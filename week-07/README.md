# שבוע 7 — UX/UI ופתיחת הפרויקט

כאן נמצאת העבודה שלך משבוע 7: ביקורת, עיצוב מחדש של אזור אחד, ותוכנית הפרויקט.

## איך עובדים כאן

1. לפני השיעור: הורד את חומרי השבוע מהמודל, העתק לכאן את כל התוכן של תיקיית ה-`starter` — כולל `vendor/` ו-`images/` — וכתוב נושא מועמד בטבלה שבראש `PROJECT_PLAN.md` (ראה `pre-class/README-he.md` בחומרי השבוע במודל).
2. **את `bad-page.html` לא עורכים.** קוראים אותו, ומבקרים אותו ב-`audit-he.md`.
3. את `redesign.html` פותחים ב-VS Code ומריצים דרך **Live Server** — לא בלחיצה כפולה על הקובץ. כותבים במקומות המסומנים `class="CODE-HERE"`, ומוחקים את הסימן.
4. `PROJECT_PLAN.md` — טיוטה מ-Claude, מתוקנת בידיים שלך, וסעיף 11 בסוף: מה הוא ניחש, מה תיקנת, ולמה.
5. עשה קומיטים קטנים ותכופים תוך כדי העבודה, לא קומיט ענק אחד בסוף.

## הגשה

במודל, שני דברים בלבד: **כתובת ה-repo** ו-**ה-SHA של הקומיט**.

```bash
git add .
git commit -m "feat: ..."
git push
git log -1 --format=%H
```

ה-SHA הוא מה שמקפיא את ההגשה. דחיפה אחרי המועד לא משנה את מה שנבדק.
