# הפרויקט

הפרויקט נפתח בשבוע 7 ומוגש בסוף שיעור 12. הוא 50% מהציון.

כאן תיכנס אפליקציית הרשימה שלך: הנושא שבחרת, הארכיטקטורה של שבוע 10
(`state` יחיד ← `render(state)` ← מטפלי אירועים שמשנים state ומרנדרים מחדש),
CRUD מלא, שמירה ב-localStorage, אינטגרציה מול API אמיתי, ומודול TypeScript אחד לפחות.

בנוסף לקוד, כאן נמצאים גם מסמכי העבודה מול ה-AI:
`PROJECT_PLAN.md`, `FEATURE_SPEC.md` לכל פיצ'ר, `PROMPTS.md` ו-`AI_USAGE.md`.
התבניות שלהם מגיעות עם הבריף בשבוע 7.

**מבחן המעבדה בשבוע 13 נעשה על הפרויקט הזה.** מה שלא תוכל להסביר — לא באמת שלך.
