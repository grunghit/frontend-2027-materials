# תוכנית פרויקט — Record Shelf

| | |
|---|---|
| **שם הסטודנט** | יוסי ארביב (דוגמה) |
| **מספר זהות** | — |
| **נושא מהמאגר / נושא עצמאי** | עצמאי — הדוגמה של המרצה, מחוץ למאגר |
| **עודכן לאחרונה** | לפני שיעור 6 |

## 1. משפט אחד

מי שאוסף אלבומים יכול לחפש אלבום בקטלוג ציבורי, לשמור אותו על מדף אישי בדפדפן,
ולדרג אותו — כדי שבעוד חצי שנה הוא יזכור למה הוא שמר אותו.

## 2. למי זה, ומה המסלול המרכזי

**המשתמש:** מישהו שקונה תקליטים לאט, שניים-שלושה בחודש, ושוכח מה הוא כבר שמע
ומה הוא רק התכוון. הוא לא רוצה רשת חברתית ולא המלצות — הוא רוצה רשימה שלו.

**המסלול המרכזי:**

1. נכנס לעמוד הראשי ורואה את המדף שלו כפי שהשאיר אותו.
2. מקליד שם אמן בשדה החיפוש ומקבל עד 24 אלבומים מהקטלוג.
3. לוחץ "הוסף למדף" על אחד מהם.
4. נכנס לעמוד האלבום, נותן דירוג ומקליד שורה אחת של הערה.
5. בביקור הבא מסנן את המדף לפי סגנון או מחפש בתוך ההערות שלו.

## 3. האוסף

**שם הישות (באנגלית):** `Album`, ועליו `ShelfEntry` — מה שהמשתמש עשה איתו.

| שדה | טיפוס | מאיפה הוא בא | מוצג? מסונן לפיו? |
|---|---|---|---|
| `id` | `string` | `collectionId` מה-API, מומר למחרוזת | מזהה, לא מוצג. נמצא ב-URL |
| `title` | `string` | `collectionName` | מוצג, מסונן, ממוין |
| `artist` | `string` | `artistName` | מוצג, מסונן, ממוין |
| `year` | `number \| null` | ארבע ספרות מ-`releaseDate` | מוצג, ממוין. `null` = "שנה לא ידועה" |
| `genre` | `string` | `primaryGenreName` | מוצג, מסונן |
| `trackCount` | `number \| null` | `trackCount` | מוצג בעמוד האלבום בלבד |
| `artwork` | `string \| null` | `artworkUrl100`, מוגדל ל-400 | מוצג. `null` = תמונת ברירת מחדל |
| `rating` | `0..5` | המשתמש | מוצג, ממוין. `0` = ללא דירוג |
| `note` | `string` | המשתמש | מוצג, **מסונן לפיו** |
| `addedAt` | `string` | `new Date().toISOString()` | ממוין לפיו. מוצג כתאריך מקומי |

שתי החלטות שכדאי להסביר:

- **`id` הוא מחרוזת ולא מספר**, למרות שה-API מחזיר מספר. הוא נכנס ל-URL ולמפתח
  של אובייקט, ושניהם מחרוזות. המרה אחת בגבול חוסכת השוואה שנכשלת בין שני
  דברים זהים.
- **`year` הוא `number | null` ולא `0`.** אלבום בלי תאריך יציאה אינו משנת אפס,
  והוא צריך למיין אחרון בשני הכיוונים.

## 4. שלושת העמודים

| קובץ | מה יש בו | מאיפה הנתונים |
|---|---|---|
| `index.html` | חיפוש בקטלוג + המדף, עם סינון, סגנון ומיון | `state.shelf` + `state.search` |
| `album.html?id=` | אלבום אחד: עטיפה, פרטים, דירוג, הערה, הסרה | `selectEntry(state, id)` |
| `stats.html` | מספרים ושני פילוחים — לפי סגנון ולפי עשור | `selectStats(state)` בלבד |

`stats.html` הוא העמוד השלישי דווקא בגלל שאין לו נתונים משלו. הוא אותו אוסף
במבט שני, וזה מה שהופך את הארכיטקטורה לדבר שרואים ולא רק מספרים עליו.

## 5. ה-API

| | |
|---|---|
| **כתובת** | `https://itunes.apple.com/search` |
| **פרמטרים** | `term=<חיפוש>&entity=album&limit=24` |
| **דורש מפתח?** | לא |
| **CORS פתוח?** | כן. בדקתי: התשובה מחזירה `access-control-allow-origin: *` |
| **מה אני לוקח מהתשובה** | 6 שדות מתוך `results[]`. השאר נזרק ב-`toAlbum()` |
| **מה קורה כשהיא לא זמינה** | מצב שגיאה עם "נסה שוב" ועם מעבר לקטלוג מקומי |

הקטלוג המקומי (`data/catalogue.json`) הוא 24 שורות אמיתיות שצילמתי מה-API,
באותם שמות שדות — כך שאותה `toAlbum()` מנרמלת את שניהם. **הוא לא מוחלף
בשקט:** מצב השגיאה מציע אותו והמשתמש בוחר, ובמצב ההצלחה כתוב מאיזה קטלוג
התוצאות. יישום שמראה נתונים מקומיים ומתאר אותם כתוצאות חיפוש משקר למשתמש.

זה גם מה שהופך את היישום לשמיש בשבוע 13, שבו אין רשת בכלל.

## 6. ארבעת המצבים

**האזור:** תוצאות החיפוש בקטלוג, `#search-results` ב-`index.html`.

| מצב | מה רואים על המסך | מה אפשר לעשות |
|---|---|---|
| ריק (עוד לא חיפשתי) | "חפש אלבום כדי להתחיל" + "הקלד שם של אמן או של אלבום בשדה שלמעלה" | להקליד |
| ריק (חיפשתי, אין) | "לא נמצאו אלבומים עבור X" + "נסה איות אחר, או חפש לפי שם האמן בלבד" | לחפש שוב |
| נטען | ארבעה כרטיסי שלד בגודל של התוצאות האמיתיות | כלום. השדה נשאר פעיל |
| שגיאה | "החיפוש בקטלוג נכשל" + המשפט הספציפי (פסק זמן / אין חיבור / קוד HTTP) | "נסה שוב" · "חפש בקטלוג המקומי" |
| הצלחה | "N תוצאות עבור X · מהקטלוג המקוון/המקומי" + כרטיסים | להוסיף למדף |

שני דברים ששווה לשים לב אליהם:

- **שני מצבים ריקים, שני משפטים.** "לא נמצאו תוצאות" לפני שהמשתמש הקליד משהו
  נראה כמו יישום שבור.
- **שלד ולא ספינר.** השלד באותו גודל של התוצאות, ולכן העמוד לא קופץ כשהן
  מגיעות, והמשתמש רואה כמה מגיע. וגם: יש לו פסק זמן של 8 שניות, כי ספינר בלי
  פסק זמן מסתובב עד שמישהו מרענן.

בנוסף, ל-`#shelf` יש **מצב ריק שלישי** שאינו אף אחד מהשניים: יש אלבומים אבל
הסינון מסתיר את כולם. שם ההודעה אומרת כמה יש בסך הכול, ויש כפתור שמנקה את
הסינון — כי הפקדים של המשתמש עצמו הם הסיבה, וכדאי לומר לו את זה.

## 7. צורת ה-state

```js
const state = {
  shelf: [],          // ShelfEntry[] — מה שנשמר ב-localStorage. זה כל האוסף
  query: '',          // סינון טקסט על המדף
  genre: 'all',       // שם סגנון, או 'all'
  sort: 'added-desc', // אחד מחמישה מפתחות מיון
  search: {           // האזור היחיד שיש רשת מאחוריו
    term: '',
    status: 'empty',  // 'empty' | 'loading' | 'error' | 'success'
    results: [],
    error: null,      // משפט בעברית, או null
    source: null,     // 'live' | 'offline' | null
  },
};
```

**מה נגזר ולא נשמר:**

- הרשימה המסוננת והממוינת — `selectVisible(state)`
- רשימת הסגנונות לתפריט הסינון — `selectGenres(state)`. מוסיפים אלבום ג'אז
  והאפשרות מופיעה; מסירים את האחרון והיא נעלמת, בלי שורת קוד בהנדלר
- כל המספרים ב-`stats.html` — `selectStats(state)`
- "N מתוך M" מעל המדף
- אם אלבום כבר על המדף (הכיתוב בכרטיס התוצאה)

`status` הוא שדה אחד ולא שלושה בוליאנים. `isLoading` + `hasError` + `isEmpty`
מאפשרים שמונה שילובים שמתוכם ארבעה חסרי משמעות, ואחד מהם יקרה.

## 8. פיצ'רים — ליבה, ואחר כך

**ליבה:**

1. חיפוש בקטלוג עם ארבעת המצבים.
2. הוספה והסרה מהמדף, עם התמדה ב-`localStorage`.
3. דירוג והערה לכל אלבום.
4. סינון, סגנון ומיון — נגזרים מ-state.
5. עמוד סיכום שכל נתוניו נגזרים.

**אם יישאר זמן:**

- ביטול (undo) אחרי הסרה, במקום דיאלוג אישור.
- מצב כהה שעובר AA בשתי הרמפות.
- ייצוא המדף לקובץ JSON.

**לא אבנה, במפורש:**

- התחברות או משתמשים. אין שרת, ואין מה לאבטח.
- נגן שמע. ה-API מחזיר קטעי דגימה וזו הסחת דעת שתאכל שבוע.
- דירוג בכוכביות שמצוירות ב-SVG. קבוצת `radio` אמיתית נותנת מקלדת בחינם.
- ניהול "אוספים" מרובים. זו ישות שנייה, כלומר פרויקט שני.
- דפדוף. 24 תוצאות זה מספיק, ודפדוף על תוצאות חיפוש הוא עוד מצב לתחזק.

## 9. סיכונים

| הסיכון | מה אעשה אם זה קורה |
|---|---|
| ה-API לא נגיש מהמעבדה (חומת אש) או בשבוע 13 | הקטלוג המקומי כבר בנוי ומוצע מתוך מצב השגיאה. זה לא תוכנית מגירה, זה פיצ'ר |
| כתובות התמונות מרחוק — עמוד בלי רשת יראה מלבנים | `artwork: null` נופל לקובץ SVG מקומי, ולקטלוג המקומי אין בכלל כתובות תמונה |
| שדה שאני צריך חסר בחלק מהשורות | `toAlbum()` מחזיר `null` לשורה שאין לה `id` או `title`, ומוותר על 1 מ-24 במקום על החיפוש כולו |
| מיון בעברית ובאנגלית מעורבב | `localeCompare(…, 'he')` בכל המשוואות, לא `<` |
