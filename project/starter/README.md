## איך מריצים

**חייב שרת. אין לפתוח בלחיצה כפולה.**

פתח את התיקייה **הזו** כתיקיית העבודה ב-VS Code, ואז `Open with Live Server` על
`index.html`.

על `file://` נשברים שלושה דברים בנפרד:

| מה נשבר | למה |
|---|---|
| `js/app.js` לא נטען | מודול ES נחסם על ידי CORS |
| `data/catalogue.json` לא נקרא | `fetch` של קובץ מקומי נדחה |
| שום דבר לא נשמר | `localStorage` משויך למקור אטום |

**אם עדכנת את `ts/types.ts`**, הרץ מהתיקייה הזו:

```bash
npx tsc -p tsconfig.json
```

הדפדפן טוען את `js/types.js` — הפלט — ולא את המקור.

**`js/state.js` ו-`js/storage.js` נשארים JavaScript כתוב ביד.** אל תיצור `ts/state.ts` או `ts/storage.ts`:
`tsc` כותב את הפלט ל-`js/` ויחליף את הקובץ שלך. במבחן בשבוע 13 עובדים על שני הקבצים האלה.

## אם משהו לא עובד

| מה קורה | כנראה |
|---|---|
| העמוד נראה בלי עיצוב בכלל | `js/theme.js` רץ אחרי `vendor/tailwind.js`, או שאחד מהם נושא `defer` — בדוק את הקונסול, יש שם הודעה מדויקת |
| `Failed to load module script` | פתחת ב-`file://`. הרץ דרך Live Server |
| הרשימה ריקה למרות שהוספת | `render(state)` לא נקרא, או שהוא קורא את ה-DOM ולא את `state` |
| כפתור עובד פעם אחת ואז מפסיק | המאזין נרשם על הפריט ולא על המכל. האצלה — ראה `events.js` |
| הפוקוס נעלם אחרי לחיצה | הפקד נמצא בתוך אזור שמרונדר מחדש. ראה כלל 1 ב-`render.js` |
| `localStorage` מכיל נתונים של פרויקט אחר | המפתח לא מרוחב שם. ראה `KEY` ב-`storage.js` |
| החיפוש מחזיר "לא נמצא" כשאין רשת | `catch` שמחזיר מערך ריק. מצב ריק ומצב שגיאה הם שני דברים |
