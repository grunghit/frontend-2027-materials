## א. "אני לא יודע מאיפה להתחיל"

**רמז.** לא מהקוד. מנייר.

**אסטרטגיה.** פתח את `images/target-1280.png` וצייר עליו מלבנים סביב כל אזור. עכשיו עשה
את אותו דבר על `target-375.png`. השווה: אלה **אותם מלבנים**, מסודרים אחרת.

זו כל שיטת העבודה של השבוע. קודם מחליטים מה האזורים, ואז כותבים אותם פעם אחת ומסדרים
אותם שלוש פעמים.

**כמעט-פתרון.** סדר העבודה בקובץ הוא סדר העבודה הנכון: שלד, כותרת, hero, כרטיסים,
עבודות, כותרת תחתונה. אל תדלג קדימה — כל סעיף מניח שהקודם עומד.

## ב. "הכותרת התחתונה מרחפת באמצע בעמוד קצר"

**רמז.** אתה מנסה לפתור את זה בגובה. הפתרון הוא בשורות.

**אסטרטגיה.** העמוד הוא grid של שלוש שורות: כותרת, תוכן, כותרת תחתונה. תן לשורת התוכן
`1fr` — היא תיקח את כל מה שנשאר — ולעמוד כולו גובה מינימלי של מסך אחד.

השתמש ב-`dvh` ולא ב-`vh`. בנייד סרגל הכתובת נעלם בגלילה, ו-`vh` נמדד מול החלון **הגדול
ביותר** — אז עמוד `100vh` תמיד קצת גבוה מדי והסרגל מכסה את התחתית.

**כמעט-פתרון.**

```css
.site {
  display: grid;
  grid-template-rows: /* three rows, and the middle one takes the rest */;
  min-height: /* one screen, in a unit that moves */;
}
```

## ג. "ה-hero לא מתפצל, או שהוא מפוצל גם בנייד"

**רמז.** הבסיס — בלי שאילתה — הוא מה שנייד מקבל. השאלה היא מה אתה **מוסיף** מעליו.

**אסטרטגיה.** בבסיס: grid בעמודה אחת עם `gap`. אין צורך אפילו ב-`grid-template-columns`.
בתוך `@media (min-width: …)` בלבד: שתי עמודות.

לעמודות השתמש ב-`minmax(0, 1fr)` ולא ב-`1fr` נקי. `1fr` הוא בעצם `minmax(auto, 1fr)`,
והמינימום `auto` הוא רוחב התוכן — וכותרת ארוכה תסרב להתכווץ.

**כמעט-פתרון.**

```css
.hero {
  display: grid;
  gap: var(--space-5);
  align-items: center;
}

@media (min-width: /* the width you chose */) {
  .hero {
    grid-template-columns: minmax(0, 1.1fr) minmax(0, 0.9fr);
  }
}
```

## ד. "איפה לשים את נקודות השבירה"

**רמז.** לא ברוחב של אייפון.

**אסטרטגיה.** הצר את החלון עד 320 והרחב לאט. שים לב לשני רגעים:

1. הרגע שבו יש **מספיק מקום** לשים את התמונה ליד הטקסט בלי שהכותרת נדחסת.
2. הרגע שבו עמודת התוכן מספיק רחבה כדי לוותר על 18rem לטובת סרגל צד.

שני המספרים האלה הם נקודות השבירה שלך. כתוב אותן ב-`em` כדי שיזוזו יחד עם מי שהגדיל את
גופן ברירת המחדל.

## ה. "הכרטיסים לא משנים עמודות בלי שאילתת מדיה"

**רמז.** `repeat(3, 1fr)` הוא תמיד שלוש. אתה צריך "כמה שנכנסים".

**אסטרטגיה.** `auto-fit` או `auto-fill` בתוך `repeat()`, עם `minmax()` שנותן רצפה. תחת
15rem הכרטיסים האלה מפסיקים להיות קריאים, אז זו הרצפה.

ההבדל בין שתי המילים מופיע רק כשיש פחות פריטים ממסלולים. `demos/04-auto-fit-fill/`
מהשיעור נמצא אצלך.

**כמעט-פתרון.**

```css
.feature-row {
  display: grid;
  grid-template-columns: repeat(/* ? */, minmax(15rem, 1fr));
  gap: var(--space-4);
}
```

## ו. "יש לי פס גלילה אופקי ואני לא מוצא ממה"

**רמז.** רוב הסיכויים שזו עמודת רשימת העבודות, או תמונה.

**אסטרטגיה.** כל מקום שכתבת בו `1fr` על עמודה שיש בה תוכן רחב — טבלה, תמונה, כתובת —
צריך להיות `minmax(0, 1fr)`. אחרת המסלול מסרב לרדת מתחת לרוחב התוכן.

הפקודה משבוע 3 עדיין עובדת. הדבק בקונסול:

```js
document.querySelectorAll('*').forEach((el) => {
  if (el.getBoundingClientRect().right > document.documentElement.clientWidth + 1) console.log(el);
});
```

## ז. "התמונות מעוותות, או שהעמוד קופץ כשהן נטענות"

**רמז.** שתי בעיות שונות, שתי תכונות שונות.

**אסטרטגיה.** `aspect-ratio` קובע כמה גדולה **התיבה** ומזמין אותה עוד לפני שהקובץ הגיע —
זה מה שמונע את הקפיצה. `object-fit: cover` קובע מה קורה **לתמונה** בתיבה בצורה לא נכונה
— זה מה שמונע את העיוות. צריך את שתיהן.

לצילומים `cover`. ללוגו — `contain`, כי חיתוך של לוגו הוא לוגו אחר.

## ח. "מה זה srcset ו-sizes, ולמה הם כבר כתובים"

**רמז.** הם כתובים כי המטלה הזו לא מלמדת אותך לכתוב אותם — היא מלמדת אותך **לא לשבור
אותם**.

**אסטרטגיה.** `srcset` מציע לדפדפן כמה קבצים ומתאר את הרוחב האמיתי של כל אחד.
`sizes` אומר לו כמה רחבה המשבצת תהיה — והוא חייב להיות **שאילתת מדיה**, כי הדפדפן בוחר
קובץ לפני שהפריסה בכלל חושבה.

זה אומר שאם שינית את הפריסה, `sizes` אולי כבר לא נכון. פתח את לשונית Network, הצר את
החלון, ותראה איזה קובץ באמת נטען.

**הבדיקה האוטומטית לא תיתן לך את הנקודות האלה עד שה-hero שלך באמת בנוי** — בכוונה. אין
טעם לשמור על תיאור של משבצת שעוד לא קיימת.

## ט. "המקטע שלי נראה מודבק"

**רמז.** אם יש לך כבר שורת כרטיסים שעובדת, יש לך כבר את התבנית.

**אסטרטגיה.** אותו `repeat(auto-fit, minmax(…, 1fr))` עובד לשורת צוות, לטבלת מחירים
ולהמלצות. זה הרעיון: ברגע שיש לך את התבנית אתה מפסיק להמציא רעיון חדש לכל שורה.

השתמש באותם טוקנים — `--space-*`, `--radius-*`, `--color-*`. מקטע שנראה מודבק הוא בדרך
כלל מקטע עם מספרים משלו.

## י. "סיימתי. מה עוד"

1. הצר מ-1280 ל-375 **פיקסל פיקסל** וחפש את הרוחב היחיד שבו משהו מכוער. יש כזה.
2. לחץ Tab לאורך העמוד כולו. כל דבר שאפשר ללחוץ עליו צריך להראות פוקוס.
3. פתח DevTools, סמן את `.site`, ולחץ על התג `grid` ליד השם. עכשיו אתה רואה את השלד שלך.
4. השווה את `styles.css` שלך עם `demos/06-three-ways/` מהשיעור — לכל אזור בעמוד, שאל את
   עצמך אם בחרת Grid או Flex **בכוונה**. זו בדיוק השאלה שתישאל בבדיקה.
