> כשהשיעור מתחיל, העמוד שלך משבוע 1 יושב ב-`week-02/` במאגר, דחוף, והסקריפט למטה מדפיס
> "4/4 — מוכן". **זמן הכיתה מתחיל בהקלדה של טופס, לא בהעתקת קבצים.**

בשבוע 2 לא בונים עמוד חדש — מצמיחים את זה של שבוע 1. הטופס, הטבלה ומעבר הנגישות נכנסים
לתוך `index.html` ו-`about.html` שכבר דחפת. מה שאפשר לעשות בבית הוא ההעתקה והדחיפה: חמש
דקות כשהכול הולך חלק, ואת החמש האלה עדיף להוציא בבית ולא על חשבון המחזור הראשון.

## מה עושים

1. **העתק את העמוד לשבוע החדש.** במאגר הסמסטר שלך: את `week-01/index.html`, `week-01/about.html`
   ואת התיקייה `week-01/images/` — לתוך `week-02/`. הקבצים צריכים להיות `week-02/index.html`
   ו-`week-02/about.html`. אל תזיז את המקור — שבוע 1 נשאר כמו שהוגש.

   אם שבוע 1 לא הלך טוב, או שאין לך עדיין עמוד: תיקיית ה-`starter` של השבוע היא עמוד גמור
   לדוגמה. העתק את התוכן שלה לתוך `week-02/` והפוך את הטקסט לשלך — השבוע לא נבדק על מה
   שהיה בשבוע 1, רק על מה שנוסף.

2. **קומיט ודחיפה.**

   ```bash
   git add week-02
   git commit -m "week-02: start from week 1"
   git push
   ```

3. **הוכח שהעמוד מוכן.** מהשורש של מאגר הסמסטר, בטרמינל המשולב של VS Code:

   ```bash
   node <נתיב לחומרים>/week-02-html-forms-a11y/pre-class/verify.mjs
   ```

   ארבע בדיקות, וכולן עוברות: Node · `npx html-validate@9` עונה (בפעם הראשונה הוא מוריד את
   הגרסה — זה לוקח רגע) · `week-02/index.html` ו-`about.html` קיימים · הקומיט האחרון דחוף. אם
   בדיקה נכשלת — הסקריפט אומר מה, ומה לעשות.

4. **תיקיית תרגול.** העתק את `week-02-html-forms-a11y/live-code/01-form-that-fails-well/start/`
   מהחומרים למקום נוח בשם `practice`, ופתח אותה ב-VS Code. יש בה את עמוד מועדון הקולנוע
   שבו מקלידים במחזור 1, וקובץ `.htmlvalidate.json` — הגדרות הוולידטור, זהות לאלה של הבודק.
   בכיתה מקלידים בה במחזורים 1, 2, 3 ו-5; שלושה מה-"אתה עושה" נעשים על `week-02/` שלך.

## אם משהו לא עובד

- `node: command not found` — Node לא מותקן או לא ב-PATH. מדריך ההתקנה של שבוע 1, סעיף 4.
- "`week-02/index.html` — הקובץ לא נמצא" — העתקת לתוך `week-02/starter/` או השארת ב-`week-01/`.
  הקובץ צריך להיות ישירות `week-02/index.html`.
- "קומיטים עדיין לא נדחפו" — `git push`. אם הוא נכשל — `setup/git-panic-he.md` של שבוע 1, המצב
  השלישי.
- הוולידטור לא עונה — פעם ראשונה עם רשת איטית. הרץ `npx html-validate@9 --version` ביד וחכה.

## ומה עם AI

לא צריך. אם משהו כאן לא ברור, שאל את Claude מה הפקודה עושה — **ואז הרץ אותה בעצמך.**
אין לך מנוי? הכול עובד גם בצ'אט החינמי, ואין בכך שום חיסרון בקורס.
