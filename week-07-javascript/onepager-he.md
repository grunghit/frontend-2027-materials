## שתי שאלות שמתבלבלות

`if (value)` שואל אם הערך **אמיתי**. `value == false` שואל אם הוא **שווה ל-false**.
הן לא אותה שאלה, ו-`[]` נופל בצדדים שונים בשתיהן.

**שמונה ערכים הם falsy, ואין אחרים:** `false` · `0` · `-0` · `0n` · `''` · `null` ·
`undefined` · `NaN`.

`'0'`, `'false'`, `[]` ו-`{}` הם **אמיתיים**. שלושה מהארבעה מגיעים משדה טופס או מ-JSON.

**הכלל:** `===` תמיד. החריג היחיד הוא `value == null`, שתופס `null` ו-`undefined`
ושום דבר אחר.

## מה המשתנה מחזיק

שבעת הטיפוסים הפשוטים **מועתקים**. כל השאר — מערכים, אובייקטים, פונקציות —
**משותפים**, ואין מילת מפתח שמסמנת מה זה מה.

```js
function addTax(list) {
  list.sort((a, b) => a - b);      // reorders the CALLER's array
  return list.map((p) => p * 1.17); // and returns a new one, so it looks innocent
}
```

**תשע מתודות משנות את המערך:** `push pop shift unshift splice sort reverse fill copyWithin`.
`sort` ו-`reverse` הן היחידות שגם **מחזירות** אותו, ולכן הן נראות כמו הקבוצה הבטוחה.

**התיקון, תמיד:** `[...list].sort(...)`.

`const` נועל את **השם**, לא את הערך. `list.push(3)` מותר; `list = [9]` לא.

## שלוש הכרזות, שלוש התנהגויות

| | `var` | `let` · `const` |
|---|---|---|
| תחום | פונקציה | בלוק |
| קריאה לפני ההכרזה | `undefined`, בשקט | **זורק** |
| מורם? | כן, ומאותחל | **כן, ולא מאותחל** |

הפער בין "הקישור קיים" ל"הקישור אותחל" הוא **האזור המת**. `let` **כן** מורם — הוא
פשוט לא מאותחל, וזו הסיבה שהקריאה נכשלת בשורה שבה הטעות ולא ארבע פונקציות משם.

**ו-`typeof`**: על שם שלא הוצהר מעולם הוא בטוח ומחזיר `"undefined"`. באזור המת הוא
**זורק**.

## סגורים — לא חידה, אלא הקובץ שלכם

```js
let state = initialState();          // nothing outside can name it
const listeners = new Set();

export const getState = () => state;
export function setState(patch) {
  state = { ...state, ...patch };
  for (const listener of listeners) listener(state);
}
```

זה `js/state.js` שלכם. ה-state הוא `let` רגיל בתוך קובץ, לא מאפיין של שום דבר —
ולכן אי אפשר להגיע אליו, ולכן הוא לא יכול להתקלקל מבחוץ.

## `this` נקבע באתר הקריאה

| נכתב | `this` הוא |
|---|---|
| `owner.fn()` | `owner` — מה שלפני הנקודה |
| `fn.call(x)` | `x` |
| `fn()` | `undefined` במודול |
| **חץ** | **מה שהיה במקום שבו נכתב** |

**הבאג שתפגשו בשבוע 8:** `el.addEventListener('click', obj.method)` — הפונקציה הועברה,
לא נקראה דרך הנקודה, וההקשר אבד. **התיקון הוא לשמור על הנקודה**, לא "להשתמש בחץ":
`() => obj.method()`.

**הכלל המעשי:** חץ ל-callback, `function` למתודה.

## חץ, וסוגריים מסולסלים

```js
(x) => x * 2         // returns
(x) => { x * 2 }     // returns undefined - braces are a body, and a body needs return
(x) => ({ id: x })   // an object - note the round brackets
```

## מיון

```js
[...list].sort((a, b) => a.year - b.year)                    // numbers
[...list].sort((a, b) => a.title.localeCompare(b.title, 'he')) // text
[...list].sort((a, b) => b.rating - a.rating ||
                          a.title.localeCompare(b.title, 'he')) // with a tie-breaker
```

`sort()` בלי משווה ממיר הכול למחרוזות: `[10, 9, 1]` יוצא `[1, 10, 9]`.
`a > b` מחזיר בוליאני, ו-`sort` רוצה מספר — אז אין "קטן מ-", והמיון יוצא **כמעט** נכון.

**ורשימה בעברית בלבד ממוינת נכון בלי משווה, במקרה.** היא נשברת ברגע שנכנס שם באנגלית.

## שני אופרטורים ששווים עשר שורות

```js
payload?.results?.[0]?.title      // undefined instead of a TypeError
const year = album.year ?? 'unknown';   // only null and undefined
const year = album.year || 'unknown';   // ALSO 0 and '' - the bug
```

דירוג 0 הוא דירוג. מחיר 0 הוא חינם. `||` זורק את שניהם.
