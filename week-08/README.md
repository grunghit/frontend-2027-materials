# שבוע 8 — JavaScript, ושיטת העבודה מול AI

כאן נמצאת העבודה שלך משבוע 8: ניבוי פלט, ארבע פונקציות טהורות, סקירה של קוד ש-Claude כתב, והמפרט
הראשון שלך עם שלושת עמודי הפרויקט.

## איך עובדים כאן

1. לפני השיעור: הורד את חומרי השבוע מהמודל, העתק לכאן את כל התוכן של תיקיית ה-`starter` — כולל `js/` ו-`vendor/` — ובדוק ש-`project/templates/` מכילה את `FEATURE_SPEC.md` ואת `PROMPTS.md` (ראה `pre-class/README-he.md` בחומרי השבוע במודל).
2. הקבצים כאן הם **מודולים**: פותחים את `exercises.html` ב-VS Code ומריצים דרך **Live Server** — לא בלחיצה כפולה על הקובץ. בלחיצה כפולה תקבל שגיאת CORS.
3. כותבים במקומות המסומנים `// CODE HERE`, `CODE HERE` ו-`class="CODE-HERE"`, ומוחקים את הסימן.
4. **חלקים א, ב ו-ג בלי AI.** חלק ד — מפרט קודם, ואז Claude, ואז סעיף 7 של המפרט.
5. עשה קומיטים קטנים ותכופים תוך כדי העבודה, לא קומיט ענק אחד בסוף.

## הגשה

במודל, שני דברים בלבד: **כתובת ה-repo** ו-**ה-SHA של הקומיט**.

```bash
git add .
git commit -m "feat: ..."
git push
git log -1 --format=%H
```

ה-SHA הוא מה שמקפיא את ההגשה. דחיפה אחרי המועד לא משנה את מה שנבדק.
