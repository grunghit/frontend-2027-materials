**המרכז האקדמי רופין · שנה ג׳**

כאן נמצאים כל חומרי הקורס: שקפים, בריפים של מטלות, קבצי פתיחה (starter), ורמזים.
המאגר הזה **ציבורי וקריאה בלבד** — העבודה שלך נמצאת במאגר הפרטי שלך.

---

## פעם אחת, בשבוע 1

```bash
git clone https://github.com/grunghit/frontend-2027-materials.git
```

## כל שבוע, לפני השיעור

```bash
cd frontend-2027-materials
git pull
```

זהו. `git pull` הוא גם מיומנות נלמדת בקורס וגם הדרך שלך לקבל את החומר החדש —
לכן הוא לא נסתר מאחורי כפתור הורדה.

> אם Git עדיין מפחיד אותך בשבועות הראשונים: אותם קבצים בדיוק מועלים גם כקובץ ZIP
> למודל, בכל שבוע. זו רשת הביטחון, לא הדרך המומלצת. עד שבוע 3 תעבוד עם `git pull`.

## איך עובדים עם זה

1. `git pull` כאן, במאגר החומרים.
2. **העתק** את תיקיית ה-`starter` של השבוע לתוך התיקייה המתאימה במאגר הפרטי שלך
   (למשל `week-03/`).
3. עבוד שם, בצע קומיטים, ודחוף.
4. הגש במודל: כתובת ה-repo הפרטי + ה-SHA של הקומיט.

**אל תעבוד בתוך המאגר הזה.** הוא ידרוס את השינויים שלך ב-`git pull` הבא, והוא גם לא
מה שנבדק.

פתרונות, מחוונים, ספקי בדיקה, הערות מרצה ומבחנים. אלה נמצאים במאגר הפרטי של הקורס
ולא מתפרסמים. אם נראה לך שמשהו כזה דלף לכאן — ספר לי מיד.
