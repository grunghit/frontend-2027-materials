## איך מתחילים — פעם אחת, בשבוע 1

המאגר הזה הוא **תבנית** בלבד: שלד ריק של תיקיות וקבצי README. אין כאן שקפים ואין כאן חומרי קורס.

1. בראש העמוד לחץ **Use this template** ← **Create a new repository**.
2. שם המאגר: `frontend-2027-<תעודת הזהות שלך>`. בחר **Private**.
3. שכפל את המאגר החדש שלך למחשב (`git clone ...`) ועבוד רק בו.

את חומרי השבוע (שקפים, בריפים, קבצי `starter` ורמזים) מורידים **מהמודל**,
ומעתיקים את מה שצריך לתוך התיקייה של אותו שבוע במאגר שלך.

## חוק ההגשה — פעם אחת, לכל הסמסטר

בכל מועד הגשה אתה מגיש **במודל** שני דברים בלבד:

1. **כתובת ה-repo** שלך.
2. **ה-SHA של הקומיט** שאותו אתה מגיש.

```bash
git add .
git commit -m "feat: add contact form"
git push
git log -1 --format=%H     # ← זה ה-SHA. העתק אותו למודל.
```

**ה-SHA הוא מה שמקפיא את ההגשה.** מה שנמצא בקומיט הזה — זה מה שנבדק. דחיפה אחרי
המועד לא משנה את הציון, וגם אין על כך ויכוח. זה עובד לשני הכיוונים: אחרי שהגשת אתה
חופשי להמשיך לעבוד על הקוד בלי לפגוע במה שכבר הוגש.

אפשר להעתיק את ה-SHA גם מהממשק של GitHub: כנס ל-**Commits**, ולחץ על כפתור ההעתקה
ליד הקומיט.

## הרצה — הכלל שלא משתנה

לחיצה כפולה פותחת את הקובץ בכתובת `file://`, וזה שובר שלושה דברים:

## בדיקות אוטומטיות

בכל דחיפה רצות בדיקות אוטומטיות על התיקייה שבה עבדת (לשונית **Actions** בגיטהאב).
הן בודקות שהעמוד תקין, נטען בלי שגיאות, ונראה סביר גם במסך צר.

**ירוק זה הרצפה, לא הציון.** הבדיקות מוכיחות שהדבר רץ. הנקודות מגיעות מהחלקים שמכונה
לא יכולה לשפוט: עיצוב, נגישות, איכות הקוד וההיגיון שמאחוריו.

אם ראית ❌ — לחץ על ההרצה וקרא את הסיכום. הוא בעברית ומסביר מה היה צפוי.
אם ראית הודעה על **תקלת תשתית** — זו תקלה אצלנו, לא בקוד שלך, ואינה משפיעה על הציון.

## היגיינת קומיטים — נבדקת מהשבוע הראשון

זו שורה במחוון של כל מטלה. לא הרבה נקודות, אבל לא אפס.

- הודעות משמעותיות בקידומת: `feat:` `fix:` `style:` `refactor:` `docs:`
- קומיטים קטנים ותכופים. קומיט אחד ענק בסוף הוא לא היסטוריה, זה גיבוי.
- לעולם לא `node_modules`, לעולם לא סיסמאות או מפתחות API.
- **לעולם לא להעלות קבצים דרך כפתור Upload File באתר של גיטהאב.** רק Git, מהטרמינל
  או מ-VS Code.
- `git pull` לפני שאתה מתחיל לעבוד, לא אחרי שכבר כתבת.
