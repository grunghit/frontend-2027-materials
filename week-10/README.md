# שבוע 10 — state, render, ומקור אמת אחד

כאן נמצאת העבודה שלך משבוע 10: המזווה, מפורק לשלוש שכבות — `js/state.js`, `js/render.js`, `js/events.js` — ו-`js/app.js` של ארבע שורות.

## איך עובדים כאן

1. לפני השיעור: הורד את חומרי השבוע מהמודל, העתק לכאן את כל התוכן של תיקיית ה-`starter` — כולל `js/` ו-`vendor/` — ודחוף (ראה `pre-class/README-he.md` בחומרי השבוע במודל).
2. פתח את התיקייה ב-VS Code והרץ דרך **Live Server** — לא בלחיצה כפולה על הקובץ: `js/app.js` הוא מודול.
3. **לפני שאתה מזיז שורה:** ארבעת הרצפים שבראש `js/app.js`, וגיליון `observations-he.md` מלא. זה חלק א.1, ובלי AI.
4. אחר כך מעבירים — לא כותבים מחדש — לשלוש השכבות, במקומות המסומנים `// CODE HERE` ו-`class="CODE-HERE"`. בחלק ג מוחקים את `js/summary.js`.
5. עשה קומיט לכל חלק: ריפקטור הוא המקום שבו קומיטים קטנים הם כלי עבודה — מי שעשה קומיט אחרי כל שכבה יכול לחזור לאמצע.

## הגשה

במודל, שני דברים בלבד: **כתובת ה-repo** ו-**ה-SHA של הקומיט**.

```bash
git add .
git commit -m "feat: ..."
git push
git log -1 --format=%H
```

ה-SHA הוא מה שמקפיא את ההגשה. דחיפה אחרי המועד לא משנה את מה שנבדק.
