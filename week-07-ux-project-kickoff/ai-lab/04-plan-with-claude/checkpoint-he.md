# נקודת ביקורת — מחזור AI 4

בסוף המחזור יש לך:

- תשובה אחת ל-P1 בצ'אט שלך, שספרת וחיפשת בה — ובדקת אותה מול הבריף של הפרויקט (שרת,
  התחברות, משתמש שני, מספר הפיצ'רים בליבה, API עם מפתח).
- P2 שכתבת **לבד**, עם התבנית כולה ועם אילוצים שאפשר לספור או לחפש, ותשובה אליו שבדקת מול
  הבריף — ואת ה-API שבה פתחת בדפדפן.
- `PROJECT_PLAN.md` על **הנושא שלך**, עם סעיף 11 מלא — שלוש שורות, כמו בדוגמה
  `ai-exemplars/exemplars/project-plan-good.md` בחומרי הקורס. למשל:

  > **מה Claude ניחש:** שנים-עשר פיצ'רים בליבה, כולל הרשמה והתחברות, סנכרון דרך שרת ושיתוף עם
  > בני משפחה; שלוש ישויות; ו-API של Perenual.
  > **מה תיקנתי:** חתכתי לחמישה בליבה (סעיף 8) והעברתי את ההתחברות, השרת והשיתוף ל"לא אבנה";
  > ישות אחת, `Plant` (סעיף 3); החלפתי את ה-API בתקציר של ויקיפדיה (סעיף 5).
  > **למה:** הבריף אומר `localStorage` בלבד ובלי משתמש שני. **בדקתי** את Perenual מעמוד ב-Live
  > Server: 400, `Missing API Key`; את ויקיפדיה: 200 עם `extract`.
