the rule

Filtering as you type is help: every keystroke shows you more of what you wanted, and there is no wrong intermediate state. Validating as you type is nagging: an error about a state the user was always going to pass through, and after a week people stop reading the messages.

So: local filtering on input. Validation on blur — then live, but only once the field is already invalid, so the message clears the moment it is fixed rather than making the user leave the field again. Network requests on submit, always.
