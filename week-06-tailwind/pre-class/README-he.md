## מה עושים

1. **משוך את החומרים.** במאגר החומרים של הקורס (הציבורי): `git pull`.
2. **העתק את תיקיית הפתיחה.** את **התוכן** של `week-06-tailwind/starter/` — `index.html`,
   `components.html`, `tindog.html`, `review-he.md`, `variants/`, `images/` **ו-`vendor/`** — לתוך
   `week-06/` במאגר הסמסטר שלך (`frontend-2027-<תעודת הזהות>`). לא את התיקייה `starter` עצמה: הקובץ
   צריך להיות `week-06/index.html`.
3. **פתח ב-Live Server** את `week-06/index.html`. מה שאתה רואה: הכותרת העליונה מעוצבת — היא ניתנה לך
   גמורה, כדוגמה — וכל השאר טקסט רגיל, אחד מתחת לשני. **זו נקודת ההתחלה, והיא לא שבורה.** אם גם הכותרת
   לא מעוצבת — `vendor/tailwind.js` לא הועתק (סעיף 2).
4. **קומיט ודחיפה.** מהשורש של מאגר הסמסטר:

   ```bash
   git add week-06
   git commit -m "week-06: starter"
   git push
   ```

5. **הוכח שהמכונה מוכנה.** הרץ מהשורש של מאגר הסמסטר שלך (הסקריפט נמצא בחומרים שמשכת):

   ```bash
   node <נתיב לחומרים>/week-06-tailwind/pre-class/verify.mjs
   ```

   ארבע בדיקות, וכולן עוברות: Node קיים · אתה בתוך מאגר git עם remote · שלושת העמודים, גיליון הסקירה,
   `variants/` ו-`vendor/tailwind.js` במקום, והעמוד טוען את Tailwind מהקובץ ולא מ-CDN · הקומיט האחרון
   נדחף. אם בדיקה נכשלת — הסקריפט אומר מה, ומה לעשות.

## אם משהו לא עובד

- `node: command not found` — Node לא מותקן או לא ב-PATH. מדריך ההתקנה של שבוע 1, סעיף Node.
- "לא בתוך מאגר git" — אתה לא בתיקיית מאגר הסמסטר. `cd` לשם ונסה שוב.
- "אין remote" — המאגר לא מחובר ל-GitHub. מדריך ההתקנה, סעיף SSH ו-`git remote add`.
- "הקומיט האחרון לא נדחף" — `git push`. אם הוא מסרב — `git-panic-he.md` בתיקיית ההתקנה.
- **התקן את התוסף Tailwind CSS IntelliSense ב-VS Code** — שגיאת כתיב במחלקה לא מייצרת שגיאה, היא
  מייצרת כלום, והתוסף אומר לך תוך כדי הקלדה.
