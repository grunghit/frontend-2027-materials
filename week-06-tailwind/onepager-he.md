## התרגום, בשש שורות

| מה שכתבת | מה שכותבים | הערה |
|---|---|---|
| `padding: 1rem` | `p-4` | הסולם הוא 0.25rem לצעד. **חלק בארבע** |
| `display: flex` | `flex` | `flex-col`, `items-center`, `justify-between` |
| `grid-template-columns: repeat(3,1fr)` | `grid-cols-3` | עד `grid-cols-12` |
| `border-radius: .75rem` | `rounded-xl` | `rounded-full` לגלולה |
| `color: ...` | `text-brand-500` | ורקע הוא `bg-*` |
| `@media (min-width: 48rem)` | `md:` | תחילית, לא בלוק |

**כשאתה לא יודע — אל תנחש.** `demos/03-translator/` מקבל הצהרת CSS ומחזיר את המחלקה על ידי **מדידה**.

## `@theme` הוא הטוקנים של שבוע 3, עם תפקיד שני

```html
<style type="text/tailwindcss">
  @theme {
    --color-brand-500: hsl(234 89% 52%);
    --spacing: 0.25rem;
  }
</style>
```

כל שם כזה הוא עדיין custom property, **ובנוסף** מייצר משפחת מחלקות — `text-brand-500`, `bg-brand-500`.
**התכונה `type="text/tailwindcss"` היא כל ההבדל:** בלעדיה הבלוק הוא CSS רגיל, השמות לא קיימים, והמחלקה
פשוט לא עושה כלום — בלי שגיאה (מחזור 1). ו-`tailwind.config` מהמדריכים הוא גרסה 3; אצלנו הוא לא נקרא.

## תחיליות ומצבים

| כותבים | מה נוצר | הערה |
|---|---|---|
| בלי תחילית | בלי שאילתה | **הטלפון. התחל כאן** |
| `md:` · `xl:` | `@media (width >= 48rem)` · `(width >= 80rem)` | נערמות, לא מתחלפות |
| `max-md:` | `@media (width < 48rem)` | דלת מילוט. **לא ברירת מחדל** |
| `order-first` | `order: -9999` | ראשון מבין **כל** הפריטים. `md:order-none` מבטל |
| `flex-1` | `flex: 1 1 0%` | חלוקה שווה. `basis-0` אחריו לא מוסיף כלום |
| `hover:` | `@media (hover: hover)` ואז `:hover` | לא נתקע בטלפון |
| `focus-visible:` | `:focus-visible` | **נבדק בכל מטלה.** רק מקלדת |
| `disabled:` | `:disabled` | אותה רשימה, המצב מחליט |
| `dark:` | `@media (prefers-color-scheme: dark)` | אין כפתור. מעלה־צבע שני, לא היפוך |
| `motion-safe:` | `@media (prefers-reduced-motion: no-preference)` | **כל מעבר** |
