# מפרט פיצ'ר — סינון ומיון של המדף

| | |
|---|---|

## 1. מה המשתמש יכול לעשות אחרי זה, ולא יכול לפניו

לצמצם מדף של ארבעים אלבומים לשלושה שהוא מחפש — לפי טקסט, לפי סגנון, ובסדר שהוא בוחר.

## 2. מה משתנה ב-state

```js
// לפני
{ shelf: [...] }
// אחרי
{ shelf: [...], query: '', genre: 'all', sort: 'added-desc' }
```

**מה במפורש לא נוסף:** `visibleShelf`. הרשימה המסוננת **נגזרת** ב-`selectVisible(state)` ולא
נשמרת. אם היא הייתה נשמרת, כל מקום שמשנה את `shelf` היה צריך לזכור לחשב אותה מחדש — וזה
בדיוק המקום שבו אחד מהם יישכח.

## 3. מה משתנה על המסך

| האזור | מה נוסף / משתנה |
|---|---|
| סרגל כלים מעל המדף | שדה חיפוש, `<select>` סגנון, `<select>` מיון. **סימון סטטי** — לא מרונדר |
| `#shelf-count` | "N מתוך M" — אחרי סינון שני המספרים שונים, וזה כל הרעיון |
| `#shelf` | מציג את `selectVisible(state)` במקום את `state.shelf` |

## 4. האירועים

| האירוע | על מה מקשיבים | מה ההנדלר עושה |
|---|---|---|
| `input` | `#shelf-query` | `setState({ query: el.value })` |
| `change` | `document` (האצלה) | `#shelf-genre`, ואז `setState({ genre })` · `#shelf-sort`, ואז `setState({ sort })` |

**החלטה:** הסרגל הוא סימון סטטי כי הוא מכיל שדה טקסט, ורינדור מחדש בכל תו היה מוחק את
השדה מתחת לסמן.

## 5. מקרי קצה

| המקרה | ההתנהגות הנכונה |
|---|---|
| הסינון הוא רווחים בלבד | `trim()` — נחשב ריק |
| סינון שלא תואם לאף אלבום | מצב ריק שלישי: "אין אלבומים שמתאימים לסינון" + כפתור ניקוי. לא "המדף ריק" |
| מיון לפי שנה כשלאלבום אין שנה | `null` אחרון בשני הכיוונים. לא כשנת 0 |
| שמות בעברית ובאנגלית | `localeCompare(…, 'he')`, לא `<` |
