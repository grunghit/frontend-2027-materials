מה הופך סקירה כזאת לטובה: **טענה ומסקנה מופרדות**, וכל מסקנה מגיעה עם הבדיקה שרצה —
רוחב, מספר, כלי. "נראה בסדר" אינו מופיע בה. שים לב גם שהחלק הארוך ביותר הוא דחיית
הגרסה **הנכונה** — כי זה החלק הקשה באמת.

---

## הבקשה

הסקירה נכתבה על מטלה של שבוע ה-Flexbox, שבו Grid עוד לא נלמד.
ביקשתי שלוש גרסאות ל"שורת שלושה כרטיסים, שווים ברוחב, שנערמים לעמודה אחת בטלפון".
חזרו שלוש. את שלושתן הרצתי על אותו `index.html`, בשלושה רוחבים: 375, 700, 1280.

## סעיף א — הגרסה שבחרתי

**בחרתי בגרסה:** `b`

```css
.row  { display: flex; flex-wrap: wrap; gap: 1.5rem; }
.card { flex: 1 1 17rem; min-width: 0; }
```

**למה דווקא היא:**

> החלטה אחת על ההורה (`flex-wrap`) ואחת על הילדים (`flex-basis`) מגדירות את הפריסה בכל רוחב,
> ואין בקובץ אף מספר של מסך. **בדקתי:** ב-1280 שלושה בשורה (כל אחד 389px ב-DevTools), ב-700
> שניים ואז אחד, ב-375 עמודה. הוספתי כרטיס רביעי ב-HTML בלי לגעת ב-CSS — הוא נכנס לשורה
> הבאה. זו התכונה שבגללה בחרתי בה: היא לא יודעת כמה כרטיסים יש.

## סעיף ב — הגרסה השבורה

**הגרסה השבורה היא:** `a`

```css
.row  { display: flex; }
.card { width: 33.333%; }
@media (max-width: 1024px) { .card { width: 50%; } }
@media (max-width: 480px)  { .card { width: 100%; } }
```

**מה בדיוק לא נכון בה?**

> ההסבר שצורף טוען: "מתחת ל-1024 הכרטיסים עוברים לשני טורים". **בדקתי ב-700:** שלושה
> כרטיסים בשורה אחת, כל אחד 217px — לא שניים. הסיבה: אין `flex-wrap`, ומכל flex הוא `nowrap`
> כברירת מחדל. `width: 50%` על פריט flex הוא רק **נקודת התחלה**; כשאין מקום לשלושה של 50 %
> הדפדפן מכווץ אותם עד שנכנסים, ולא מוריד אחד לשורה. ב-375 אותו דבר: שלושה כרטיסים של 113px
> עם כותרות שנשברות באמצע מילה. מעל 1024 הגרסה נכונה, וזו בדיוק הסיבה שהיא שורדת מבט ראשון.

**איך גילית את זה?**

> לא מהקוד — מהדפדפן. פתחתי ב-700 וספרתי שורות. אחר כך חזרתי לקוד ושאלתי "מה מונע מהם
> לגלוש", ורק אז ראיתי שאין `flex-wrap`.

**מה התיקון, ולמה דווקא הוא?**

> לא הוספתי `flex-wrap` לגרסה `a` — זה היה מתקן אותה, אבל משאיר שתי שאילתות מדיה שכל אחת
> מהן היא כלל שצריך לבטל ברוחב הבא. עברתי לגרסה `b`: אותה תוצאה, אפס שאילתות.

## סעיף ג — למה דחיתי את הגרסה הנכונה השנייה

**הגרסה הנכונה שדחיתי היא:** `c`

```css
.row { display: grid; grid-template-columns: repeat(auto-fit, minmax(17rem, 1fr)); gap: 1.5rem; }
```

**נימוק:**

> היא נכונה, ובדקתי: אותן שלוש תוצאות בשלושת הרוחבים, ואותו כרטיס רביעי נכנס לבד. דחיתי אותה
> מסיבה אחת שאינה טכנית: Grid היה החומר של השבוע הבא, והמטלה של אותו שבוע אסרה אותו במפורש כדי
> ללמד מה פריסה חד-ממדית יכולה לבד. **מתי כן הייתי בוחר בה:** כשהכרטיסים צריכים להתיישר גם
> בעמודות — שורה שנייה שבה שני כרטיסים לא נמתחים על כל הרוחב. ב-flex הכרטיס האחרון בשורה
> חלקית גדל; ב-Grid הוא נשאר ברוחב עמודה. ברגע שזו הדרישה, `c` היא התשובה.

## מה למדתי על הפרומפט

ביקשתי "רספונסיבי" וקיבלתי שתי שאילתות מדיה כברירת מחדל — כי כך רוב הקוד בעולם כתוב.
בפעם הבאה: **"בלי שאילתות מדיה; הגלישה נעשית עם `flex-wrap`"** בגוף הבקשה. וכל טענה על
"מתחת ל-X זה עובר ל-Y" נבדקת ברוחב שבין X ל-Y, לא בקצוות.
