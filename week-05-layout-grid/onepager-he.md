## הקוד שכדאי לדעת בעל פה

```css
.page {
  display: grid;                        /* alone, this is ONE column */
  grid-template-columns: minmax(0, 1fr);/* the phone is the base */
  grid-template-areas: 'top' 'main' 'side' 'foot';
  gap: 1rem;
}

@media (min-width: 40em) {              /* min-width: each query ADDS */
  .page {
    grid-template-columns: minmax(0, 1fr) minmax(0, 3fr);
    grid-template-areas: 'top top' 'side main' 'foot foot';
  }
}

.cards {
  display: grid;                        /* as many as fit, none under 15rem */
  grid-template-columns: repeat(auto-fit, minmax(15rem, 1fr));
  gap: 1rem;
}

.shot img {
  aspect-ratio: 3 / 2;                  /* the BOX */
  object-fit: cover;                    /* the PICTURE inside it */
}
```

## חמשת הכללים של השבוע

1. **`display: grid` לבדו נותן עמודה אחת.** בלי רשימת מסלולים — ובלי פסיקים בה — "Grid לא עובד".
2. **`fr` הוא חלק ממה שנשאר אחרי ה-`gap`.** אחוז הוא אחוז מהמכל, והרווח לא בחשבון.
3. **`1fr` הוא `minmax(auto, 1fr)`** — הוא לא יורד מתחת לתוכן. `minmax(0, 1fr)` מוריד את הרצפה.
4. **אזור פריסה לא מקבל גובה קבוע.** `aspect-ratio` כשצריך צורה; התוכן כשלא.
5. **נקודת שבירה באה מהתוכן**, נכתבת ב-`min-width` וב-`em`, ונבדקת בגרירה — לא בשלושה מכשירים.

## המטלה, בשש נקודות

1. **ה-HTML גמור** ו-`week-05/` כבר במאגר שלך (מהבית). אתה כותב רק `styles.css`.
2. הציור: ארבע על ארבע ב-`fr`, ריבועי בלי גובה, תשעה אזורים לפי קווים. *(מחזור 2)*
3. הלוח: שמונה על שמונה, משבצות ריבועיות, ו-`:nth-child` עם המחזור הנכון. *(מחזור 2)*
4. השלד: ציור של חמישה שמות, עמודה אחת בבסיס, שתי שאילתות `min-width`. *(מחזורים 1 ו-5)*
5. שורת הכרטיסים: `auto-fit` + `minmax`, בלי שאילתה; הפנים של `.kpi` נשאר Flexbox. *(מחזור 3)*
6. הרחבה — לוח הסטטוס עם `aspect-ratio` ו-`object-fit` *(מחזור 3)*, מספר זורם ו-hover בלי פריסה
   *(ה-"אתה עושה" של מחזור 5)*. אתגר — כרטיס רחב, `dense`, ו-`subgrid` בתוך `@supports`.

**אסור השבוע:** `@media (max-width: …)` · גובה קבוע על אזור פריסה · `!important` · Tailwind ·
JavaScript · `transition` על `width`/`height`/`top`/`left`/`margin`/`padding` או `all`.

## חמש הטעויות שיעלו לך זמן

| הטעות | מה נכון |
|---|---|
| `display: grid` ולא קרה כלום | חסרה רשימת מסלולים — או שיש בה פסיק |
| הלוח יצא בפסים | ברוחב זוגי `odd` לא מתחלף בין שורות. המחזור הוא שתי שורות |
| הפריסה מבולגנת ולא שבורה | שורה ב-`grid-template-areas` עם מספר תאים שונה. ספור |
| פס גלילה אופקי | `1fr` שלא מתכווץ. `minmax(0, 1fr)` על המסלול |
| תמונות מעוכות | `aspect-ratio` בלי `object-fit: cover` |
