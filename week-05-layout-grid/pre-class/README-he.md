> כשהשיעור מתחיל, `week-05/` כבר במאגר שלך, שני העמודים נפתחים ב-Live Server, והסקריפט למטה
> מדפיס "4/4 — מוכן". **זמן הכיתה מתחיל בנושא, לא בהקמה.**

כמו בשבועות הקודמים, ההקמה — "הקם את התיקייה, העתק, פתח" — נעשית בבית: כדי שבדקה 145,
כשחלון המטלה נפתח, אתה כותב CSS ולא מחפש תיקייה.

## מה עושים

1. **משוך את החומרים.** במאגר החומרים של הקורס (הציבורי): `git pull`.
2. **העתק את תיקיית הפתיחה.** את **התוכן** של `week-05-layout-grid/starter/` — `index.html`,
   `warmup.html`, `styles.css`, `images/` — לתוך `week-05/` במאגר הסמסטר שלך
   (`frontend-2027-<תעודת הזהות>`). לא את התיקייה `starter` עצמה: הקובץ צריך להיות
   `week-05/index.html`.
3. **פתח ב-Live Server** את `week-05/index.html` ואת `week-05/warmup.html`. מה שאתה רואה הוא
   ערימה — לוח מחוונים שכל האזורים שלו אחד מתחת לשני, וציור ולוח שהם בינתיים רק רשימה של
   תיבות. **זו נקודת ההתחלה, והיא לא שבורה.** ביום שלישי היא תקבל ממד שני.
4. **קומיט ודחיפה.** מהשורש של מאגר הסמסטר:

   ```bash
   git add week-05
   git commit -m "week-05: starter"
   git push
   ```

5. **הוכח שהמכונה מוכנה.** הרץ מהשורש של מאגר הסמסטר שלך (הסקריפט נמצא בחומרים שמשכת):

   ```bash
   node <נתיב לחומרים>/week-05-layout-grid/pre-class/verify.mjs
   ```

   ארבע בדיקות, וכולן עוברות: Node קיים · אתה בתוך מאגר git עם remote · `week-05/index.html`,
   `warmup.html` ו-`styles.css` במקום, וה-HTML מקשר לגליון · הקומיט האחרון נדחף. אם בדיקה
   נכשלת — הסקריפט אומר מה, ומה לעשות.

## אם משהו לא עובד

- `node: command not found` — Node לא מותקן או לא ב-PATH. מדריך ההתקנה של שבוע 1, סעיף Node.
- "לא בתוך מאגר git" — אתה לא בתיקיית מאגר הסמסטר. `cd` לשם ונסה שוב.
- "אין remote" — המאגר לא מחובר ל-GitHub. מדריך ההתקנה, סעיף SSH ו-`git remote add`.
- "הקומיט האחרון לא נדחף" — `git push`. אם הוא מסרב — `git-panic-he.md` בתיקיית ההתקנה.

אין לך מנוי? הכול עובד גם בצ'אט החינמי, ואין בכך שום חיסרון בקורס.
