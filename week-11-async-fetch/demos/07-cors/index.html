what you CAN do about it

        
    
          
  • Pick an API that sends the header. Check before you build — see the brief's list.
    • 
          
  • 
            Put a server of your own in the middle. It has no browser and therefore no CORS; it
            fetches and re-serves with the header. Not this course — but it is the real
            answer, and it is why every production app has one.
          
    • 
          
  • Ask the API's owner to add the header. Sometimes this works.
    • 
        

      

      

        
what you CANNOT do about it

        
    
          
  • Anything at all in your JavaScript. No header you SEND changes what it RECEIVES.
    • 
          
  • 
            mode: 'no-cors'. It stops the error by giving you an
            opaque response: status 0, no body, nothing readable. It does not fetch the data,
            it stops you asking for it.
          
    • 
          
  • 
            A browser extension that disables the check. It fixes YOUR laptop and nobody else's,
            including the machine your project is graded on.
          
    • 
          
  • try/catch. It catches the TypeError. It does not get the data.
