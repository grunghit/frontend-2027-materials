# שבוע 6 — Tailwind: העמוד נכתב במחלקות

כאן נמצאת העבודה שלך משבוע 6: לוח המחוונים של שבוע 5, בנוי מחדש בלי גיליון סגנון, עם סט רכיבים
וסקירה כתובה של שלוש תשובות של Claude.

## איך עובדים כאן

1. **לפני השיעור** (`pre-class/README-he.md` בחומרי השבוע במודל): הורד את חומרי השבוע מהמודל, העתק לכאן את **תוכן** תיקיית ה-`starter` — `index.html`, `components.html`,
   `tindog.html`, `review-he.md`, `variants/`, `images/` **ו-`vendor/`** — ודחוף. `pre-class/verify.mjs`
   מדפיס "4/4 — מוכן".
2. פתח את התיקייה ב-VS Code והרץ דרך **Live Server**. לא בלחיצה כפולה על הקובץ.
3. ה-HTML גמור ואין לגעת בו. כל העבודה בתכונות ה-`class`, במקומות המסומנים `CODE-HERE`, ובגיליון
   `review-he.md`.
4. `vendor/tailwind.js` **נשאר במאגר** — הוא Tailwind עצמו, מקומי, כי בשבוע 13 אין רשת.
5. עשה קומיטים קטנים ותכופים תוך כדי העבודה, לא קומיט ענק אחד בסוף.

## מה אסור השבוע

גיליון סגנון משלך · `style=""` · `@apply` · `!important` · Tailwind מ-CDN או `tailwind.config`. הבריף מסביר למה.

## הגשה

במודל, שני דברים בלבד: **כתובת ה-repo** ו-**ה-SHA של הקומיט**.

```bash
git add week-06
git commit -m "feat: ..."
git push
git log -1 --format=%H
```

ה-SHA הוא מה שמקפיא את ההגשה. דחיפה אחרי המועד לא משנה את מה שנבדק.
