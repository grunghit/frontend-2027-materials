## שני המשפטים של השבוע

**טיפוסים מתארים צורה, לא כוונה — ו-`as` הוא הצהרה, לא בדיקה.**

**ארגון מחדש הוא שינוי שאינו משנה התנהגות. אם ההתנהגות השתנתה, לא ארגנת — שינית.**

---

## מה נמחק בקומפילציה, ומה לא

| מה שכתבת            | קיים בזמן ריצה? |
| ------------------- | --------------- |
| `interface`         | לא              |
| `type`              | לא              |
| `: string` על פרמטר | לא              |
| `as X`              | לא              |
| `<T>` בגנריקה       | **לא**          |
| `function isX(...)` | **כן**          |
| `instanceof`        | **כן**          |
| `typeof`            | **כן**          |

**כל מה שבחצי העליון נעלם.** לכן מה שיוצא מ-localStorage ומהרשת נבדק בחצי התחתון, ולא
מתואר בעליון.

## ארבע דרכים לומר "זה מסוג X", ומה כל אחת שווה

| מה כותבים    | מה זה אומר              | מה רץ                                    |
| ------------ | ----------------------- | ---------------------------------------- |
| `: any`      | תפסיק לבדוק, כאן ובהמשך | כלום                                     |
| `: unknown`  | אף אחד עוד לא בדק       | כלום — **אבל אסור לגעת עד שמישהו יבדוק** |
| `as T`       | אני מבטיח שזה T         | כלום                                     |
| `value is T` | הנה ההוכחה              | **גוף הפונקציה**                         |

## הגבול, בשלוש שורות

```ts
let payload: unknown;
payload = await res.json();
return toSuggestions(payload);
```

`res.json()` מוגדר בטיפוסי ה-DOM כמחזיר `Promise<any>` — **לא** `unknown`. בלי ההצהרה
המפורשת, גישה לכל שדה בתשובה עוברת את המהדר בשקט, גם על מסמך שגיאה של 404.

## שגיאות המהדר שתפגוש היום, ומה הן אומרות

| ההודעה                                                    | מה לעשות                                      |
| --------------------------------------------------------- | --------------------------------------------- |
| `Property 'x' does not exist on type 'unknown'`           | בדיוק מה שביקשת. צריך שומר לפני הגישה         |
| `'x' is possibly 'null'`                                  | הוא באמת עשוי להיות. פסוק שמירה, או `$()`     |
| `NodeListOf<Element> must have a '[Symbol.iterator]'`     | חסר `"DOM.Iterable"` ב-`lib`. **כבר שם אצלך** |
| `Type 'Date' is not assignable to type 'string'`          | זה הבאג של שבוע 10, שנתפס לפני ההרצה          |
| `'error' is of type 'unknown'` בתוך `catch`               | `error instanceof Error` לפני `error.name`    |
| `Cannot assign to 'x' because it is a read-only property` | `readonly` תפס מוטציה. **החלף במקום לשנות**   |

**ארבעים שגיאות אינן ארבעים בעיות.** תקן את הראשונה בלבד, הרץ שוב, וספור.

## שלוש הטעויות שכלי AI עושה כאן, כל פעם

1. **`catch (error: any)`** — התיקון הראשון שהוא מציע תחת `strict`, והוא מכבה בדיוק את
   מה שביקשת. הנכון\: `error instanceof Error`.
2. **`(await res.json()) as X`** — מהדר, קצר יותר, בודק בדיוק כלום.
3. **`async function getJson<T>(url): Promise<T>`** — נראה מקצועי, **ואין `T` בזמן
   ריצה.** הגרסה הכנה מקבלת שומר כפרמטר.

## איך מארגנים מחדש בבטחה כשאין בדיקות

1. **מהלך אחד בכל פעם.** חילוץ, או שינוי שם — לא שניהם.
2. **בדיקה אחרי כל אחד.** רענון, לחיצה, השוואה למסך. עשר שניות.
3. **קומיט אחרי כל אחד.** ככה מגלים איזה מהלך שבר.
4. **רשום מה אסור שישתנה לפני שאתה מתחיל** — שלוש התנהגויות, ואיך תבדוק כל אחת.
5. **אם אי אפשר לבדוק, אל תעשה.** צמצם את ההיקף עד שאפשר.

## שלוש שאלות לפני שאתה יוצא

1. כתבת `interface Item` וקימפלת. **מה נמצא בקובץ הפלט?**
2. `res.json()` החזיר מסמך שגיאה של 404. **מי מבין `any`, `unknown` ו-`as` אמר לך?**
3. העברת קובץ אחד מתוך שישה. **כמה מהם נבדקים עכשיו על ידי המהדר?**

**התשובות\:** (1) שום דבר מהטיפוס — רק השומר. (2) אף אחד; `unknown` רק מנע ממך לגעת עד
שבדקת, וזה לא אותו דבר. (3) **שישה** — ה-`.d.ts` נותן את הטיפוסים גם למי שנשאר
JavaScript, וזו כל הסיבה שהעברה הדרגתית עובדת.
