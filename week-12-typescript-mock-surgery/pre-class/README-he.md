> [!goal]
> כשהשיעור מתחיל, `npx tsc --version` מדפיס `Version 5.9.3` **בלי רשת**, תיקיית המטלה יושבת
> ב-`week-12/` במאגר **כמו שהיא נשלחה**, הכול דחוף, והסקריפט למטה מדפיס "5/5 — מוכן". **חלון המטלה
> השבוע הוא עשר דקות**, כי הניתוח המלא לוקח חמישים דקות מהבלוק — ואין בו זמן להתקנות.

בשבוע 12 מריצים את המהדר של TypeScript מהדקה העשירית. במאגר הסמסטר אין `package.json` ואין
`node_modules`, ולכן המהדר מותקן **פעם אחת, גלובלית**, ו-`npx tsc` מוצא אותו לבד.

## מה עושים

1. **התקן את המהדר.** בטרמינל, מכל מקום:

   ```bash
   npm install --global typescript@5.9.3
   npx tsc --version
   ```

   השורה השנייה מדפיסה `Version 5.9.3`. **אם `npx` מציע להוריד חבילה בשם `tsc` — ענה "לא".** זו
   גרסה ישנה ונטושה בשם דומה, לא המהדר; התקן את `typescript` כמו בשורה הראשונה.

2. **העתק את תיקיית הפתיחה.** מהחומרים: את כל התוכן של `week-12-typescript-mock-surgery/starter/` —
   כולל `ts/`, `js/`, `specs/`, `data/` ו-`vendor/` — לתוך `week-12/` במאגר הסמסטר שלך. **אל תמלא עדיין
   את `specs/ts-migration.md`** — הוא הדבר הראשון שכותבים בשיעור, לפני כל כלי AI, והקומיט שלו הוא הראיה.

3. **הרץ אותה פעם אחת** ב-Live Server (לא בלחיצה כפולה: `js/` הוא מודולים). חפש מילה בפאנל
   הקטלוג — מגיעות תוצאות. זה המסך שיישאר **זהה** אחרי ההעברה.

4. **קומיט ודחיפה.**

   ```bash
   git add week-12
   git commit -m "week-12: starter, untouched"
   git push
   ```

5. **הוכח שהכול במקום.** מהשורש של מאגר הסמסטר, בטרמינל המשולב של VS Code:

   ```bash
   node <נתיב לחומרים>/week-12-typescript-mock-surgery/pre-class/verify.mjs
   ```

   חמש בדיקות, וכולן עוברות: Node · `git` והמאגר · המהדר, נמצא בלי רשת · קובצי הפתיחה ב-`week-12/`,
   ומתקמפלים כמו שהם · הקומיט האחרון דחוף. אם בדיקה נכשלת — הסקריפט אומר מה, ומה לעשות.

6. **תיקיית תרגול.** העתק את `week-12-typescript-mock-surgery/live-code/01-rename-and-compile/start/`
   מהחומרים למקום נוח בשם `practice`, ופתח בה טרמינל. יש בה ספריית ההשאלה של הכיתה — ארבעה מודולים
   ב-JavaScript ו-`tsconfig.json`, אותו קובץ כמו במטלה. שם מתחיל מחזור 1. לשאר המחזורים מעתיקים בכיתה
   את ה-`start/` של כל אחד.

## אם משהו לא עובד

- `node: command not found` — Node לא מותקן או לא ב-PATH. מדריך ההתקנה של שבוע 1, סעיף 4.
- "npx לא מצא את tsc מותקן" — שלב 1 לא הושלם, או שהטרמינל נפתח לפניו. סגור ופתח את הטרמינל, והרץ שוב
  את `npx tsc --version`.
- "חסרים: vendor/tailwind.js" — העתקת את הקבצים ולא את התיקיות. העתק את התיקיות כמו שהן.
- "כבר יש ts/api.ts" — התחלת להעביר. המטלה מתחילה במפרט: מחק את `ts/api.ts`, והעבר בשיעור, אחריו.
- "קומיטים עדיין לא נדחפו" — `git push`. אם הוא נכשל — `setup/git-panic-he.md` של שבוע 1.
