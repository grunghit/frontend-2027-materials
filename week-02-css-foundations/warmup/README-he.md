# חימום שבוע 2 — שמונה הצהרות

**עשר דקות. בלי Git, בלי הגשה, בלי ציון.** זה מה שפותח את המעבדה.

## מה יש כאן

`index.html` הוא עמוד תקין לגמרי. ה-markup בסדר גמור, והוא בדיוק מהצורה שלמדת בשבוע
שעבר. מה שהופך אותו לכואב לקריאה הוא **שמונה הצהרות ב-`styles.css`**, וכל אחת מהן היא
החלטה שאנשים אמיתיים מקבלים באמת — בדרך כלל כי זה נראה בסדר על המחשב שלהם.

## מה עושים

1. פתח את התיקייה ב-VS Code והרץ את `index.html` ב-Live Server.
2. פתח את `styles.css` **לצד** העמוד.
3. תקן הצהרה אחת, שמור, והסתכל. אחת בכל פעם.
4. אחרי שמונה — השווה עם `target.png`.

**אין צורך באף תכונה שלא כתובה כבר בקובץ.** התיקון של כל אחת מהשמונה הוא **ערך אחר**,
לא כלל חדש.

## למה זה נראה כמו מעט

זו בדיוק הנקודה. אחרי שמונה שינויים העמוד נעים לקריאה, ואין בו שום עיצוב: אין מערכת
צבע, אין סולם, אין אופי. **זו הרצפה** — והמטלה של היום היא מה שקורה מעליה.

## אם נשאר לך זמן

עבור על שמונה השורות ושאל על כל אחת: **איך היא הייתה נראית בטלפון?** שתיים מהן נעשות
גרועות בהרבה במסך צר, ואחת מהן דווקא כמעט לא מזיקה שם. איזו?
