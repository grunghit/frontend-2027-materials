The first website is still online

And it has not been redesigned once.

Nineteen ninety-one

The first web page went up at CERN in 1991, on a NeXT machine with a note taped to it asking people not to switch it off. It explained what the World Wide Web was, listed a few links, and was written in a version of HTML with about twenty elements in it. You can still open it today, in any browser, and it renders.

That is not nostalgia — it is the single most important promise the web platform makes. Nothing you write this semester will stop working because a company changed its mind. A page from 1991 and a page you write tonight are read by the same parser.

What it did not have

It had no CSS. Not because the author had bad taste, but because CSS did not exist yet: the first proposal came in 1994 and the first browser support in 1996. For five years every page on the web looked like the one you are reading right now, and everybody thought that was simply what a document was.

Which is worth remembering when your own page looks plain in week one. So did all of them.
