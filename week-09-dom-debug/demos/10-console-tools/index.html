Six calls, the question each one answers, and the output mirrored on the page

A card with two data- attributes, for dir to look at.

Mirrored output — the console has the same thing in it

Open DevTools (F12 · Cmd+Option+I), then press a button.

Which one answers which question

question call
what is in this array of objects? console.table(list)
what properties does this element have? console.dir(el)
which of these forty lines belong together? console.group / groupEnd
how many times did this really run? console.count(label)
how long did that take? console.time / timeEnd
who called this function? console.trace()

Two more that only exist in the console itself, so they cannot be on this page: $0 is the element you last selected in the Elements panel, and $$('li.card') is querySelectorAll with less typing. Select something in Elements, switch to Console, type $0.
