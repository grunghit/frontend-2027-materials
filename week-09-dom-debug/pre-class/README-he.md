## מה עושים

1. **העתק את תיקיית הפתיחה.** מהחומרים: את כל התוכן של `week-09-dom-debug/starter/` — כולל `js/`,
   `vendor/` ו-`debug/` — לתוך `week-09/` במאגר הסמסטר שלך. **את `debug/` לא פותחים לעריכה עד
   האתגר**: הוא שבור בכוונה, והקונסולה שלו אדומה בטעינה. זה בסדר.

2. **קומיט ודחיפה.**

   ```bash
   git add week-09
   git commit -m "week-09: starter"
   git push
   ```

3. **הוכח שהכול במקום.** מהשורש של מאגר הסמסטר, בטרמינל המשולב של VS Code:

   ```bash
   node <נתיב לחומרים>/week-09-dom-debug/pre-class/verify.mjs
   ```

   ארבע בדיקות, וכולן עוברות: Node · `git` והמאגר · קובצי הפתיחה ב-`week-09/`, כולל `debug/` ו-`debug-he.md` ·
   הקומיט האחרון דחוף. אם בדיקה נכשלת — הסקריפט אומר מה, ומה לעשות.

4. **תיקיית תרגול.** העתק את `week-09-dom-debug/live-code/01-render-from-the-array/start/` מהחומרים
   למקום נוח בשם `practice`, ופתח אותה ב-VS Code עם Live Server. יש בה The Tool Shelf — שלוש שורות
   שהוקלדו ב-HTML ומערך עם אותם שלושה כלים. שם מתחיל מחזור 1. למחזורים הבאים מעתיקים בכיתה את
   ה-`start/` של כל אחד.

## אם משהו לא עובד

- `node: command not found` — Node לא מותקן או לא ב-PATH. מדריך ההתקנה של שבוע 1, סעיף 4.
- "חסרים: debug/index.html" — העתקת את הקבצים ולא את התיקיות. העתק את `js/`, `vendor/` ו-`debug/` כמו שהן.
- העמוד לבן ובקונסולה שגיאה על `import` — פתחת בלחיצה כפולה. הקוד כאן מודולים, ומודול לא נטען מעל
  `file://`: Live Server, תמיד.
- "קומיטים עדיין לא נדחפו" — `git push`. אם הוא נכשל — `setup/git-panic-he.md` של שבוע 1.

## ומה עם AI

לא צריך. אם משהו כאן לא ברור, שאל את Claude מה הפקודה עושה — **ואז הרץ אותה בעצמך.** ואל תפתח את
`debug/js/app.js` עם Claude "רק כדי להציץ": האתגר הוא בלי AI, והגיליון הוא ההוכחה.
אין לך מנוי? הכול עובד גם בצ'אט החינמי, ואין בכך שום חיסרון בקורס.
