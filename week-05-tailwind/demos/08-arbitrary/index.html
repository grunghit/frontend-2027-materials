The test, and it is mechanical:

Would you want a second element to have this exact value?

  yes → it is a decision. Give it a name in @theme.

  no → it is a one-off. Brackets are the right answer.

And then: is it already on the scale, or within one step of it? If so you are overriding a system that was working, and that is the smell.

correct a size somebody else decided

A leaderboard slot is 728×90 because the ad network says so. Nobody on this team chose it, nobody will reuse it, and rounding it to the scale would break the thing. Brackets, no apology.

728 × 90 
class="w-[728px] h-[90px] …"

correct a property with no utility at all

There is no utility for mask-image, and there should not be — it is used once in a career. The arbitrary-property form takes any declaration at all, and using it here is not a defeat. 

class="[mask-image:linear-gradient(to_right,black,transparent)]"

belongs in @theme the same colour, nine times

Nine swatches that are all meant to be the brand colour, each typed as a literal. How many colours can you see? Count them, then read the audit. 

class="bg-[#182df2]"   …nine times, by hand

the fix:
  @theme { --color-brand-500: hsl(234 89% 52%); }
  class="bg-brand-500"

the smell one pixel off the scale, three times

Three boxes whose padding was nudged until each one looked right on its own. Every value is within two pixels of a real step. This is the case the test exists for.

p-[13px]
p-[15px]
p-[22px]
p-4
