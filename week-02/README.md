# שבוע 2 — HTML II: טפסים, טבלאות, והקורא שלא רואה

כאן נמצאת העבודה שלך משבוע 2: העמוד של שבוע 1, מוצמח.

## איך עובדים כאן

1. **לפני השיעור:** העתק את `week-01/index.html`, `week-01/about.html` ואת `week-01/images/` לכאן
   (`week-02/index.html`, `week-02/about.html`, `week-02/images/`). אל תזיז את המקור — שבוע 1 נשאר כמו
   שהוגש. אם שבוע 1 לא הלך טוב — הורד את חומרי השבוע מהמודל והעתק לכאן
   את תוכן תיקיית ה-`starter` במקום.
2. פתח את התיקייה ב-VS Code והרץ דרך **Live Server**. לא בלחיצה כפולה על הקובץ.
3. הוסף את הטופס, הטבלה, ה-`time`, קישור הדילוג ו-`aria-current` — במקומות שהבריף מציין. אם התחלת
   מה-`starter`, המקומות מסומנים `<!-- CODE HERE -->`.
4. `npx html-validate@9 index.html about.html` מהתיקייה הזאת — אפס שגיאות; הגדרות הוולידטור
   (`.htmlvalidate.json`) נמצאות בשורש המאגר.
5. עשה קומיטים קטנים ותכופים תוך כדי העבודה, לא קומיט ענק אחד בסוף.

## מה אסור השבוע

CSS · JavaScript · `aria-label` על שדות טופס · `tabindex` חיובי. הבריף מסביר למה.

## הגשה

במודל, שני דברים בלבד: **כתובת ה-repo** ו-**ה-SHA של הקומיט**.

```bash
git add week-02
git commit -m "feat: ..."
git push
git log -1 --format=%H
```

ה-SHA הוא מה שמקפיא את ההגשה. דחיפה אחרי המועד לא משנה את מה שנבדק.
