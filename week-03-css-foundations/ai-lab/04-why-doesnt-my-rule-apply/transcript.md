## Claude

הכלל שלך לא חל בגלל **ספציפיות**, לא בגלל הסדר בקובץ.

הכותרת מקבלת את הצבע שלה משני כללים שמתחרים על אותה תכונה:

- `#page-title { color: grey; }` — בורר לפי **id**.
- `.title { color: hsl(170 70% 28%); }` — בורר לפי **מחלקה**.

ל-id יש ספציפיות גבוהה יותר מכל מחלקה: `#page-title` הוא `(1,0,0)`, ו-`.title` הוא `(0,1,0)`.
כשהדפדפן מכריע בין הצהרות שמתחרות על אותה תכונה, הוא משווה ספציפיות **לפני** סדר המקור.
סדר המקור מכריע רק כשהספציפיות שווה — ולכן "הכלל שלי אחרון" לא עוזר כאן: ה-id מנצח
אותו בכל מקום בקובץ.

אפשר לראות את זה ב-DevTools: בחר את ה-`h1`, ובפאנל Styles ההצהרה `color` של `.title`
מופיעה מחוקה בקו, ומעליה `#page-title` עם ה-`grey`.

**התיקון הכי מהיר** — תן לבורר שלך ספציפיות שווה או גבוהה יותר, על ידי שילוב ה-id עם
המחלקה:

```css
#page-title.title {
  color: hsl(170 70% 28%);
}
```

זה `(1,1,0)`, שגובר על `(1,0,0)`. הכלל נשאר בסוף הקובץ, וגם אם הספציפיות הייתה שווה הוא
היה מנצח בסדר המקור.

אפשרות מהירה עוד יותר היא `!important`:

```css
.title {
  color: hsl(170 70% 28%) !important;
}
```

זה עובד, אבל עדיף להימנע ממנו: ברגע ש-`!important` בקובץ, הדרך היחידה לדרוס אותו היא
`!important` נוסף, וזה מצטבר מהר.

**לטווח ארוך** עדיף לא לעצב לפי id בכלל. אם הכלל של המדריך היה `h1 { color: grey; }` או
`.page-title { color: grey; }`, ה-`.title` שלך היה מנצח באופן טבעי — או בספציפיות או בסדר
המקור — בלי לשלב בוררים.

> **מכשול.** ההסבר נכון עד המילה האחרונה, והתיקון עובד ברגע שמריצים אותו — הופעל על
> `artifact/claude-p1/` ונמדד: הכותרת `rgb(21, 121, 105)`, 5.08 : 1 על הרקע, ובפאנל Styles
> `#page-title` מחוק בקו. ובדיוק שם הבעיה: התשובה **העלתה את המפסיד** — `(0,1,0)` הפך
> ל-`(1,1,0)` — במקום להוריד את המנצח, ואת האפשרות הזאת שמה בסוף, כ"לטווח ארוך". מה
> שהיא לא בדקה: הקובץ שהודבק כבר מכיל כלל מחלקה נוסף על אותה כותרת — `.title` בבלוק
> `@media (prefers-color-scheme: dark)`, `(0,1,0)` — והוא **מפסיד עכשיו לתיקון**. נמדד
> ב-Rendering עם `prefers-color-scheme: dark`: הקישורים `rgb(133, 224, 209)` (הצבע הבהיר
> של הערכה הכהה), הכותרת **נשארה** `rgb(21, 121, 105)` — הטורקיז של הערכה הבהירה על רקע
> `rgb(20, 31, 29)`, 3.19 : 1. ועוד מדידה: כלל `.title { color: … }` שמוסיפים **אחרי הכול**
> — לא משנה את הכותרת; ב-`claude-p2/` הוא כן. `!important`, ההצעה השנייה, היה עושה את
> אותו הדבר בדיוק, רק עם חוב גדול יותר. איך רואים את זה בחדר: מפעילים את התיקון, ואז
> Rendering ← dark — הכותרת בצבע הלא נכון והקישורים בצבע הנכון. השאלה ביקשה "הכי מהיר";
> התשובה נתנה את המהיר, ואת הנכון בהערת שוליים. ההסבר של הספציפיות היה החלק שצריך
> לאמץ; הכיוון של התיקון — החלק שצריך לשאול עליו.

## Claude

**השלשות, והשלב שהכריע.**

| הכלל | הבורר | שלשה `(id, class, element)` |
|---|---|---|
| של המדריך | `#page-title` | `(1,0,0)` |
| שלך | `.title` | `(0,1,0)` |

המפל בודק ארבעה דברים בסדר: מקור (גיליון הדפדפן מול שלך — שניהם שלך, תיקו), חשיבות (אין
`!important` — תיקו), **ספציפיות** — `(1,0,0)` מול `(0,1,0)`, משווים עמודה-עמודה, והעמודה
הראשונה מכריעה: **כאן נגמר**. סדר המקור, השלב הרביעי, לא נבדק בכלל.

**התיקון — להוריד את המנצח.** ה-id נשאר ב-HTML כעוגן; רק הבורר בגיליון משתנה. הכותרת
היא ה-`h1` היחיד בעמוד, אז הכלל של המדריך יכול לבחור אותה לפי האלמנט:

```css
/* was #page-title (1,0,0). Lowered to the element (0,0,1): the id stays in
   the HTML as an anchor, and every class rule below can now override this. */
h1 {
  color: grey;
  font-size: 2rem;
  line-height: 1.15;
}
```

עכשיו `h1` הוא `(0,0,1)` ו-`.title` הוא `(0,1,0)` — המחלקה מנצחת בשלב הספציפיות, בלי
שום שינוי בכלל שלך. וזה תופס גם את הכלל השני שכבר יש לך על אותה כותרת: `.title` בתוך
`@media (prefers-color-scheme: dark)`, גם הוא `(0,1,0)`, מנצח את `h1` באותו אופן — ובינו
לבין ה-`.title` הרגיל, ששווים בספציפיות, מכריע סדר המקור: הבלוק הכהה מאוחר יותר, אז
בערכה הכהה הכותרת מקבלת את הצבע הבהיר.

אם היית רוצה להשאיר את הבחירה לפי ה-id בלי לשלם עליה בספציפיות — `:where(#page-title)`
הוא `(0,0,0)`, ו-`[id="page-title"]` הוא `(0,1,0)` — אבל בעמוד עם `h1` אחד, `h1` הוא הבורר
שאומר מה שהוא מתכוון.

**איך לבדוק בפאנל Styles.** Elements, בחר את ה-`h1`. בפאנל Styles ההצהרות מסודרות מהמנצח
למטה: `.title { color: hsl(170 70% 28%) }` למעלה, ומתחתיו `h1 { color: grey }` עם ה-`color`
**מחוק בקו**. בלשונית Computed, `color` מראה `rgb(21, 121, 105)` — ולחיצה על החץ לידו אומרת
מאיזה כלל הערך הגיע.

**ובערכה הכהה.** DevTools ← שלוש הנקודות ← More tools ← Rendering ← `Emulate CSS media
feature prefers-color-scheme` ← `dark`. באותו פאנל Styles מופיע עכשיו הכלל מהבלוק הכהה
למעלה, `.title { color: hsl(170 60% 70%) }`, ומתחתיו ה-`.title` הרגיל וה-`h1`, שניהם מחוקים
בקו. Computed: `rgb(133, 224, 209)` — אותו צבע כמו הקישורים.

> נמדד על `artifact/claude-p2/`: בהיר — הכותרת `rgb(21, 121, 105)`, 5.08 : 1; כהה — הכותרת
> `rgb(133, 224, 209)` על `rgb(20, 31, 29)`, 10.92 : 1, זהה לקישורים. וכלל `.title` שמוסיפים
> אחרי הכול — משנה את הכותרת. הקובץ עדיין בלי `!important`, ה-HTML לא השתנה.
