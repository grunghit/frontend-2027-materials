> כשהשיעור מתחיל, העמוד שלך משבוע 2 יושב ב-`week-03/` במאגר עם שורת `link` בכל עמוד, דחוף,
> והסקריפט למטה מדפיס "4/4 — מוכן". **זמן הכיתה מתחיל בהקלדה של CSS, לא בהעתקת קבצים.**

בשבוע 3 לא בונים עמוד חדש — מעצבים את זה של שבוע 2. אף אלמנט בו לא משתנה; מה שנוסף הוא קובץ
אחד, `styles.css`, ושורה אחת בכל עמוד שמצביעה עליו. מה שאפשר לעשות בבית הוא ההעתקה, השורה
והדחיפה: חמש דקות כשהכול הולך חלק, ואת החמש האלה עדיף להוציא בבית ולא על חשבון המחזור הראשון.

## מה עושים

1. **העתק את העמוד לשבוע החדש.** במאגר הסמסטר שלך: את `week-02/index.html`, `week-02/about.html`
   ואת התיקייה `week-02/images/` — לתוך `week-03/`. אל תזיז את המקור — שבוע 2 נשאר כמו שהוגש.

   אם שבוע 2 לא הלך טוב, או שאין לך עדיין עמוד: תיקיית ה-`starter` של השבוע היא עמוד גמור
   לדוגמה. העתק את התוכן שלה לתוך `week-03/` — השבוע לא נבדק על ה-HTML, רק על הגיליון.

2. **שורת `link` אחת** ב-`head` של כל אחד משני העמודים, אחרי ה-`title`:

   ```html
   <link rel="stylesheet" href="styles.css" />
   ```

   ולידם קובץ `week-03/styles.css` — ריק בינתיים, או עם ההערות מ-`starter/styles.css`. הוא מתמלא בכיתה.

3. **קומיט ודחיפה.**

   ```bash
   git add week-03
   git commit -m "week-03: start from week 2, link the stylesheet"
   git push
   ```

4. **הוכח שהעמוד מוכן.** מהשורש של מאגר הסמסטר, בטרמינל המשולב של VS Code:

   ```bash
   node <נתיב לחומרים>/week-03-css-foundations/pre-class/verify.mjs
   ```

   ארבע בדיקות, וכולן עוברות: Node · `git` והמאגר · `week-03/index.html`, `about.html` ו-`styles.css`
   קיימים ושני העמודים מצביעים על הגיליון · הקומיט האחרון דחוף. אם בדיקה נכשלת — הסקריפט אומר
   מה, ומה לעשות.

5. **תיקיית תרגול.** העתק את `week-03-css-foundations/live-code/01-attach-and-lose/start/`
   מהחומרים למקום נוח בשם `practice`, ופתח אותה ב-VS Code. יש בה את עמוד מועדון הקולנוע משבוע
   שעבר, בלי CSS — שם מקלידים במחזורים 1, 2, 3 ו-5. שלושה מה-"אתה עושה" נעשים על `week-03/` שלך.

## אם משהו לא עובד

- `node: command not found` — Node לא מותקן או לא ב-PATH. מדריך ההתקנה של שבוע 1, סעיף 4.
- "`week-03/index.html` — הקובץ לא נמצא" — העתקת לתוך `week-03/starter/` או השארת ב-`week-02/`.
  הקובץ צריך להיות ישירות `week-03/index.html`.
- "אין שורת `link`" — היא ב-`head`, לא ב-`body`, ו-`href="styles.css"` — בלי תיקייה, כי הקובץ
  ליד העמוד.
- "קומיטים עדיין לא נדחפו" — `git push`. אם הוא נכשל — `setup/git-panic-he.md` של שבוע 1.
