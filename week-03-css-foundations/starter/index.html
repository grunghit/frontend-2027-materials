Reading notes: what the browser actually does

Written on 2 November 2027, after the second lab.

The browser asks for one text file, turns the name into an address first, encrypts the connection, gets text back, parses it into a tree, and paints. Six words: request, DNS, TLS, response, parse, paint.

Three things I got wrong in the first hour: I opened the page by double-clicking it and wondered why the path to my image broke; I used h4 for a subheading because h2 looked too big; I wrote three br tags to push a paragraph down the page.
