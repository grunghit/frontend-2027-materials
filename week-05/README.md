# שבוע 5 — Grid ורספונסיביות

כאן נמצאת העבודה שלך משבוע 5: עמוד החימומים (ציור ולוח שחמט) ולוח מחוונים שנפרס אחרת בשלושה
רוחבים — ב-Grid, mobile-first.

## איך עובדים כאן

1. **לפני השיעור** (`pre-class/README-he.md` בחומרי השבוע במודל): הורד את חומרי השבוע מהמודל, העתק לכאן את **תוכן** תיקיית ה-`starter` — `index.html`, `warmup.html`,
   `styles.css`, `images/` — ודחוף. `pre-class/verify.mjs` מדפיס "4/4 — מוכן".
2. פתח את התיקייה ב-VS Code והרץ דרך **Live Server**. לא בלחיצה כפולה על הקובץ.
3. שני קבצי ה-HTML גמורים ואין לגעת בהם. כל העבודה ב-`styles.css`, במקומות המסומנים `/* CODE HERE */`.
4. עשה קומיטים קטנים ותכופים תוך כדי העבודה, לא קומיט ענק אחד בסוף.

## מה אסור השבוע

`@media (max-width: …)` · גובה קבוע על אזור פריסה · `!important` · Tailwind · JavaScript ·
`transition` על `width`/`height`/`top`/`left`/`margin`/`padding` או `all`. הבריף מסביר למה.

## הגשה

במודל, שני דברים בלבד: **כתובת ה-repo** ו-**ה-SHA של הקומיט**.

```bash
git add week-05
git commit -m "feat: ..."
git push
git log -1 --format=%H
```

ה-SHA הוא מה שמקפיא את ההגשה. דחיפה אחרי המועד לא משנה את מה שנבדק.
