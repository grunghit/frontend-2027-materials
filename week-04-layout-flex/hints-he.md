## א. "שמתי `display: flex` ושום דבר לא זז"

**רמז.** `display: flex` משפיע על **הילדים הישירים** של האלמנט שכתבת עליו, ועל כלום אחר.
שאל את עצמך: מי הילדים הישירים כאן, ובכמה מהם מדובר?

**אסטרטגיה.** פתח את כלי הפיתוח, בחר את האלמנט, ותסתכל בלשונית Elements. ליד אלמנט שהוא
מכל flex יופיע תג קטן שכתוב עליו `flex` — **לחץ עליו.** הדפדפן יצייר לך על העמוד את
הצירים, את הרווחים ואת המקום הפנוי. אם התג לא מופיע, ההצהרה לא תפסה, וזו בעיית בורר ולא
בעיית פריסה.

שתי סיבות נפוצות שההצהרה לא תפסה: כתבת אותה על הילד במקום על ההורה, או שהבורר שלך לא
מתאים לאף אלמנט (בדוק את הכתיב).

**כמעט-פתרון.**

```css
/* not on the item — on whatever holds the items */
.card-row {
  display: flex;
}
```

## ב. "התפריט לא נפתח / לא נסגר / תמיד פתוח"

**רמז.** `details` פותח ונסגר לבד, בלי שורת JavaScript אחת. אם הוא לא מתנהג — כנראה ה-CSS
שלך מכריח אותו. ואם הוא **תמיד** פתוח מעל הסף, זו לא תקלה: זה בדיוק מה שביקשנו בסעיף 4.

**אסטרטגיה.** יש כאן שני מצבים שונים שקל לבלבל ביניהם:

1. **מתחת ל-48em** — הפקד מוצג, הקישורים מוסתרים עד שלוחצים. **אל תיגע בזה.** זו התנהגות
   ברירת המחדל של `details` והיא כבר עובדת.
2. **מעל 48em** — הפקד נעלם, והקישורים מוצגים **בלי קשר** למצב הפתיחה.

הטעות הכי נפוצה: לכתוב את הכלל של מצב 2 מחוץ לשאילתת המדיה. אז הקישורים מוצגים תמיד, גם
בנייד, והפקד מיותר.

**כמעט-פתרון.**

```css
@media (min-width: 48em) {
  .nav-toggle {
    display: none;
  }

  /* the two given lines are already here. do not delete them. */

  .nav-disclosure .nav-links,
  .nav-disclosure[open] .nav-links {
    /* the rule has to hold in both states, open and closed — hence both selectors */
  }
}
```

## ג. "המותג והתפריט לא מתיישרים / לא מתרחקים זה מזה"

**רמז.** אלה שתי שאלות שונות. יישור אנכי הוא הציר המשני; ההרחקה היא הציר הראשי.

**אסטרטגיה.** שתי דרכים נכונות להרחקה, ואתה בוחר:

- `justify-content: space-between` על **המכל** — "סדר את הפריטים בקצוות". קורא טוב כשיש
  בדיוק שניים והסידור הוא הנקודה.
- `margin-inline-start: auto` על **הפריט האחרון** — "דחוף אותי לקצה". קורא טוב כשיש חמישה
  פריטים ואתה רוצה שרק אחד ייפרד מהשאר.

הרעיון מאחורי השנייה הוא זה: **מרווח אוטומטי בולע את כל המקום הפנוי.** בתוך flex זה הופך
אותו מכלי מרכוז לכלי מיקום.

**כמעט-פתרון.**

```css
.site-nav {
  display: flex;
  align-items: center;      /* the cross axis — this is what centres vertically */
  justify-content: space-between;
  gap: var(--space-4);
}
```

## ד. "ה-hero לא מתקפל בנייד" או "האיור נמתח ומכוער"

**רמז.** שתי בעיות נפרדות, ולשתיהן תשובה בת מילה אחת. הראשונה: `flex-wrap`. השנייה:
`align-items`.

**אסטרטגיה.** לגלישה — מכל flex הוא `nowrap` כברירת מחדל, כלומר "תדחסו, אל תגלשו". תן לו
רשות לגלוש, ותן לטקסט `flex-basis` שאומר מאיזה רוחב הוא מתחיל. כשאין מקום ל-basis ולאיור
יחד, האיור יורד לשורה משלו.

לאיור — ברירת המחדל של `align-items` היא `stretch`, כלומר "מתחו את כל הפריטים לגובה
השורה". על `img` זה נראה בדיוק כמו שזה נשמע. הפתרון הוא למרכז את הפריטים במקום למתוח אותם,
וזה גם מה שאתה רוצה ויזואלית.

**כמעט-פתרון.**

```css
.hero {
  display: flex;
  flex-wrap: wrap;          /* without this it never wraps */
  align-items: center;      /* without this the illustration stretches */
  gap: var(--space-6);
}

.hero-text {
  flex: 1 1 26rem;          /* "I want 26rem. if there is not room, take a whole row" */
}
```

## ה. "הכרטיסים לא נערמים בנייד" או "הם נערמים תמיד"

**רמז.** אלה בדיוק שני הצדדים של אותו מספר. ה-`flex-basis` שנתת לכרטיס הוא **הרוחב שהוא
מבקש**, וממנו נגזר כמה מהם נכנסים לשורה.

**אסטרטגיה.** עשה את החשבון בקול. אם ה-basis הוא `17rem` ויש שני רווחים של `1.5rem`, שלושה
כרטיסים דורשים בערך `54rem` — כלומר בערך 864 פיקסלים. מעל זה נכנסים שלושה; מתחת לזה אחד
מהם גולש.

- נערמים תמיד? ה-basis גדול מדי (או שכתבת `width` במקום `flex-basis`, ואז אין ל-flex מה
  לחלק).
- לא נערמים לעולם? חסר `flex-wrap: wrap`, או שנתת basis באחוזים שתמיד מסתדר.

**אל תוסיף שאילתת מדיה כאן.** אם אתה מרגיש שאתה חייב — המספר לא נכון, לא הכלי.

**כמעט-פתרון.**

```css
.card-row {
  display: flex;
  flex-wrap: wrap;
  gap: var(--space-5);
  padding: 0;               /* a ul arrives with padding as well as bullets */
  margin: 0;
  list-style: none;
}

.card {
  flex: 1 1 17rem;          /* this number IS the decision. change it and look. */
}
```

## ו. "הכפתורים בחבילות לא מיושרים לתחתית"

**רמז.** החבילות כבר באותו גובה — זה קרה לבד. השאלה היא איפה בתוך החבילה יושב הכפתור, וזו
שאלה על **הפריסה הפנימית של החבילה**, לא על השורה.

**אסטרטגיה.** שני שלבים, ובסדר הזה:

1. הפוך כל חבילה בעצמה למכל flex, בכיוון עמודה. עכשיו הכותרת, המחיר, הרשימה והכפתור הם
   פריטים על ציר אנכי.
2. תן לכפתור `margin-block-start: auto`. אותו רעיון בדיוק כמו בסעיף ג': **מרווח אוטומטי
   בולע את כל המקום הפנוי** — וכל המקום הפנוי נמצא מעליו.

זה עובד בלי קשר לכמה שורות יש ברשימה, וזו הנקודה.

**כמעט-פתרון.**

```css
.plan {
  display: flex;
  flex-direction: column;
}

.plan .button {
  margin-block-start: auto;
}
```

## ז. "יש לי פס גלילה אופקי ואני לא מוצא ממה"

**רמז.** כמעט תמיד זה פריט flex שמסרב להתכווץ. ה-`min-width` שלו הוא `auto` ולא `0`, והוא
לא ייכנס מתחת לרוחב התוכן שלו.

**אסטרטגיה.** קודם כול, **מצא את האשם** במקום לנחש. פתח את הקונסול והדבק:

```js
[...document.querySelectorAll('*')].filter(
  (el) => el.getBoundingClientRect().right > document.documentElement.clientWidth + 1,
);
```

מה שיחזור הוא רשימת האלמנטים שחורגים ימינה. האשם הוא בדרך כלל **הראשון ברשימה**, ולרוב הוא
פריט flex שיש בו כותרת ארוכה, תמונה, או מילה שאי אפשר לשבור.

התיקון הוא על **הפריט**, לא על המכל, ולא על `flex-shrink` — אפשר להעלות אותו ל-10 ולא יקרה
כלום, כי shrink מותר לכווץ רק עד המינימום.

**כמעט-פתרון.**

```css
.hero-text {
  flex: 1 1 26rem;
  min-width: 0;        /* the line that lifts the floor */
}
```

## ח. "התג נחת בפינת המסך במקום בפינת הכרטיס"

**רמז.** ה-CSS של התג נכון לגמרי. הבעיה היא במי שהוא נמדד ממנו, וזה לא הוא — זה ההורה.

**אסטרטגיה.** `position: absolute` הולך למעלה בעץ עד שהוא מוצא אב שה-`position` שלו אינו
`static`, ומודד ממנו. אם אין אף אחד — הוא מודד מהעמוד. **הוא לא זורק שגיאה ולא כותב אזהרה**,
ולכן זה מבלבל.

בדוק בקונסול מי באמת מעגן אותו:

```js
document.querySelector('.card-badge').offsetParent;
```

אם מה שחזר אינו הכרטיס — מצאת את הבאג.

**התיקון הוא על הכרטיס, והוא לא מזיז כלום.** זו הסיבה שקל לשכוח אותו.

**כמעט-פתרון.**

```css
.card {
  position: relative;   /* "measure from me" — and that is all it does */
}

.card-badge {
  position: absolute;
  inset-block-start: -0.75rem;
  inset-inline-end: 1rem;
}
```

   חיפוש.
