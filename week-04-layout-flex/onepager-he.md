## הקוד שכדאי לדעת בעל פה

```css
.row {
  display: flex;        /* on the parent, not on the item */
  flex-wrap: wrap;      /* without this it never wraps */
  align-items: center;  /* the cross axis */
  gap: 1.5rem;          /* not margin */
}

.item {
  flex: 1 1 17rem;      /* "I want 17rem; if there is not room, take a row" */
  min-width: 0;         /* the line that saves you from a horizontal scrollbar */
}
```

## ארבעת הכללים של השבוע

1. **תיבת בלוק** לוקחת את כל הרוחב שהציעו לה ונערמת. **תיבה שורתית** לוקחת את רוחב התוכן
   וזורמת. `display` מחליט איזו תיבה כל אלמנט מייצר.
2. **`position: absolute` נמדד מהאב הממוקם הקרוב ביותר.** אם אין אף אחד — מהעמוד. הוא לא
   זורק שגיאה; הוא פשוט עוגן במקום אחר.
3. **`z-index` משווה רק בין אחים באותו הקשר ערימה.** להעלות את המספר לא עוזר לעולם.
4. **`justify-content` הוא הציר הראשי, `align-items` הוא המשני.** איזה מהם אופקי נקבע
   ב-`flex-direction`, שורה אחת קודם.

## חמש הטעויות שיעלו לך זמן

| הטעות | מה נכון |
|---|---|
| `display: flex` ולא קרה כלום | כתבת אותו על הפריט. הוא הולך על **ההורה** |
| `ul` עם מרווח משמאל שלא נעלם | `padding: 0` ו-`list-style: none`. זה עיצוב רשימה, לא פריסה |
| התג נחת בפינת המסך | חסר `position: relative` על **הכרטיס**, לא על התג |
| `z-index` לא עוזר כמה שלא תעלה | אב יצר הקשר ערימה — `opacity`, `transform` או `filter` |
| פס גלילה אופקי | פריט flex שלא מתכווץ. `min-width: 0` **על הפריט** |

## איך למצוא גלילה אופקית בשנייה

הדבק בקונסול. מה שחוזר הוא מה שחורג:

```js
[...document.querySelectorAll('*')].filter(
  (el) => el.getBoundingClientRect().right > document.documentElement.clientWidth + 1,
);
```
