One question Flexbox cannot answer

On a phone the links should hide behind a Menu button. On a laptop there is room for them, and no reason to hide anything. Flexbox arranges the boxes it is given; it has no opinion about how wide the screen is, and no way to ask.

So this page gets exactly one media query. Open it at 375 and at 1280 and watch which half of the bar each width shows.
