> כשהשיעור מתחיל, `week-04/` כבר במאגר שלך, העמוד נפתח ב-Live Server, והסקריפט למטה מדפיס
> "4/4 — מוכן". **זמן הכיתה מתחיל בנושא, לא בהקמה.**

כמו בשבועות הקודמים, ההקמה — "הקם את התיקייה, העתק, פתח" — נעשית בבית: כדי שבדקה 145,
כשחלון המטלה נפתח, אתה כותב CSS ולא מחפש תיקייה.

## מה עושים

1. **משוך את החומרים.** במאגר החומרים של הקורס (הציבורי): `git pull`.
2. **העתק את תיקיית הפתיחה.** את **התוכן** של `week-04-layout-flex/starter/` — `index.html`,
   `styles.css`, `images/` — לתוך `week-04/` במאגר הסמסטר שלך (`frontend-2027-<תעודת הזהות>`).
   לא את התיקייה `starter` עצמה: הקובץ צריך להיות `week-04/index.html`.
3. **פתח ב-Live Server** את `week-04/index.html`. מה שאתה רואה הוא ערימה — כותרת, טקסט, איור, כרטיסים,
   אחד מתחת לשני. **זו נקודת ההתחלה, והיא לא שבורה.** ביום שלישי היא תפסיק להיות ערימה.
4. **קומיט ודחיפה.** מהשורש של מאגר הסמסטר:

   ```bash
   git add week-04
   git commit -m "week-04: starter"
   git push
   ```

5. **הוכח שהמכונה מוכנה.** הרץ מהשורש של מאגר הסמסטר שלך (הסקריפט נמצא בחומרים שמשכת):

   ```bash
   node <נתיב לחומרים>/week-04-layout-flex/pre-class/verify.mjs
   ```

   ארבע בדיקות, וכולן עוברות: Node קיים · אתה בתוך מאגר git עם remote · `week-04/index.html` ו-`styles.css`
   במקום, וה-HTML מקשר לגליון · הקומיט האחרון נדחף. אם בדיקה נכשלת — הסקריפט אומר מה, ומה לעשות.

## אם משהו לא עובד

- `node: command not found` — Node לא מותקן או לא ב-PATH. מדריך ההתקנה של שבוע 1, סעיף Node.
- "לא בתוך מאגר git" — אתה לא בתיקיית מאגר הסמסטר. `cd` לשם ונסה שוב.
- "אין remote" — המאגר לא מחובר ל-GitHub. מדריך ההתקנה, סעיף SSH ו-`git remote add`.
- "הקומיט האחרון לא נדחף" — `git push`. אם הוא מסרב — `git-panic-he.md` בתיקיית ההתקנה.

## ומה עם AI

לא צריך. אם משהו כאן לא ברור, שאל את Claude מה הפקודה עושה — **ואז הרץ אותה בעצמך.**
אין לך מנוי? הכול עובד גם בצ'אט החינמי, ואין בכך שום חיסרון בקורס.
