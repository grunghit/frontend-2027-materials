# שבוע 4 — פריסה I — זרימה, מיקום ו-Flexbox

כאן נמצאת העבודה שלך משבוע 4: עמוד הנחיתה של האתר האישי, פרוס ב-Flexbox.

## איך עובדים כאן

1. **לפני השיעור** (`pre-class/README-he.md` בחומרי השבוע במודל): הורד את חומרי השבוע מהמודל, העתק לכאן את **תוכן** תיקיית ה-`starter` — `index.html`, `styles.css`,
   `images/` — ודחוף. `pre-class/verify.mjs` מדפיס "4/4 — מוכן".
2. פתח את התיקייה ב-VS Code והרץ דרך **Live Server**. לא בלחיצה כפולה על הקובץ.
3. ה-HTML גמור ואין לגעת בו. כל העבודה ב-`styles.css`, במקומות המסומנים `/* CODE HERE */` — ורק פריסה.
4. עשה קומיטים קטנים ותכופים תוך כדי העבודה, לא קומיט ענק אחד בסוף.

## מה אסור השבוע

Grid · `float` לפריסה · `position` לפריסה · יותר משאילתת רוחב אחת · `!important` · `style=""`. הבריף מסביר למה.

## הגשה

במודל, שני דברים בלבד: **כתובת ה-repo** ו-**ה-SHA של הקומיט**.

```bash
git add week-04
git commit -m "feat: ..."
git push
git log -1 --format=%H
```

ה-SHA הוא מה שמקפיא את ההגשה. דחיפה אחרי המועד לא משנה את מה שנבדק.
