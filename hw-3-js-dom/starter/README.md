## איך מריצים את זה

1. פתח את **התיקייה הזו** ב-VS Code — לא קובץ בודד.
   הדרך הבטוחה: לחיצה כפולה על הקובץ `hw-3-js-dom.code-workspace`.
2. בפעם הראשונה VS Code יציע להתקין את ההרחבות המומלצות. **אשר.**
   אלה הכלים שכל הקורס מסתמך עליהם, ואינך צריך להגדיר דבר מעבר לזה.
3. לחץ לחיצה ימנית על `index.html` ובחר **Open with Live Server**.

> **הכלל מהשבוע הראשון: עמוד נפתח תמיד דרך Live Server, אף פעם לא בלחיצה כפולה.**
>
> לחיצה כפולה פותחת את הקובץ בכתובת `file://`, וזה שובר שלושה דברים שתצטרך בהמשך:
> `fetch` (שבוע 11), מודולים של ES (שבוע 8), ו-`localStorage` שמשויך למקור (שבוע 11).
> הרגל שנוצר בשבוע 1 מתפוצץ בשבוע 11. תתחיל נכון.

כל מקום כזה הוא מקום שבו אתה כותב. שאר הקוד הוא הפיגום — אל תמחק אותו.

## הגשה

ההגשה במודל, ומכילה שני דברים בלבד:

1. **כתובת ה-repo הפרטי שלך** בגיטהאב.
2. **ה-SHA של הקומיט** שאותו אתה מגיש.

```bash
git add .
git commit -m "feat: add contact form"
git push
git log -1 --format=%H
```

הפקודה האחרונה מדפיסה את ה-SHA. **ה-SHA הוא מה שמקפיא את ההגשה** — דחיפה אחרי המועד
לא משנה את מה שנבדק, ואין על כך ויכוח.

## היגיינת קומיטים — נבדקת ומזכה בנקודות

- הודעות קומיט משמעותיות: `feat:` / `fix:` / `style:` / `refactor:` / `docs:`.
- קומיטים קטנים ותכופים, לא קומיט ענק אחד בסוף.
- לעולם לא `node_modules`, לעולם לא סיסמאות או מפתחות.
- לעולם לא להעלות קבצים דרך כפתור **Upload File** באתר של גיטהאב. רק Git מהטרמינל או מ-VS Code.
