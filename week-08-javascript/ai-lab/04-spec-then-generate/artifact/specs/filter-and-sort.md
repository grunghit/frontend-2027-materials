## 1. מה המשתמש יכול לעשות אחרי זה, ולא יכול לפניו

לצמצם את רשימת הקריאה לספרים שהוא מחפש, ולסדר אותם לפי שם או לפי שנה.

## 2. מה משתנה ב-state

```js
// לפני
{ books: [...] }
// אחרי
{ books: [...], query: '', sort: 'none' }
```

**שדות חדשים:** `query` (`string`, `''`) · `sort` (`'none' | 'title' | 'year'`, `'none'`).

**מה במפורש לא נוסף:** `visibleBooks`. הרשימה שעל המסך **נגזרת** —
`filterAndSort(state.books, state.query, state.sort)` — ולא נשמרת. **`books` לעולם לא מסודר מחדש:**
הפונקציה קוראת אותו ומחזירה מערך חדש, בכל מסלול.

## 3. מה משתנה על המסך

| האזור | מה נוסף / משתנה |
|---|---|
| סרגל כלים מעל הרשימה | שדה חיפוש ו-`<select>` מיון. **סימון סטטי, מחוץ ל-`<ul id="list">`** — לא מרונדר |
| `#list` | מציג את מה ש-`filterAndSort` מחזירה |
| `#count` | "N מתוך M ספרים" |
| הניווט | שלושה קישורים; `aria-current="page"` על הקישור של העמוד הנוכחי |

## 5. מקרי קצה

| המקרה | ההתנהגות הנכונה |
|---|---|
| חיפוש ריק, או רווחים בלבד | כל הספרים, בסדר שבו הגיעו |
| אותיות גדולות וקטנות, רווחים מסביב | לא משנים: `' DUNE '` מוצא את `dune` |
| ספר בלי כותרת (`title: null`) | לא מפיל את הרשימה, ולא נמצא בשום חיפוש |
| מיון לפי שנה, וספר בלי שנה | ספר בלי שנה **אחרון** — לא כשנת 0 |
| מיון לפי שם, עברית ואנגלית יחד | `localeCompare(…, 'he')`, לא `<` |
| מפתח מיון לא מוכר | הרשימה המסוננת, בסדר שבו הגיעה |
