בשבוע 8 כותבים JavaScript בשלושה מחזורים, ואחרי ההפסקה Claude כותב קוד מתוך מפרט שאתה כותב. המפרט
מועתק מתבנית, והיומן מועתק מתבנית — ומי שמגיע בלי שתיהן מבזבז את תחילת מחזור 4 על חיפוש.

## מה עושים

1. **העתק את תיקיית הפתיחה.** מהחומרים: את כל התוכן של `week-08-javascript/starter/` — כולל `js/`
   ו-`vendor/` — לתוך `week-08/` במאגר הסמסטר שלך.

2. **תבניות הפרויקט.** אם עוד אין לך `project/templates/` במאגר, העתק אותה מהחומרים של הפרויקט (היא
   הגיעה עם הבריף בשבוע 7). צריכים שם שני קבצים: `FEATURE_SPEC.md` ו-`PROMPTS.md`.

3. **פתח את `week-08/exercises.html` ב-Live Server, לא בלחיצה כפולה.** הספסל נטען, ורוב השורות אדומות —
   זה נכון, עוד לא כתבת כלום. אם כתוב CORS, פתחת את הקובץ ישירות; Live Server.

4. **קומיט ודחיפה.**

   ```bash
   git add week-08 project
   git commit -m "week-08: starter and templates"
   git push
   ```

5. **הוכח שהכול במקום.** מהשורש של מאגר הסמסטר, בטרמינל המשולב של VS Code:

   ```bash
   node <נתיב לחומרים>/week-08-javascript/pre-class/verify.mjs
   ```

   חמש בדיקות, וכולן עוברות: Node · `git` והמאגר · קובצי הפתיחה ב-`week-08/` · שתי התבניות · הקומיט
   האחרון דחוף. אם בדיקה נכשלת — הסקריפט אומר מה, ומה לעשות.

6. **אופציונלי:** אם תחביר JavaScript חדש לך ולא רק שונה — `primer/` בחומרים של השבוע, תשעה תרגילים עם
   פתרונות. לא נבדק, לא נבחן.

## אם משהו לא עובד

- `node: command not found` — Node לא מותקן או לא ב-PATH. מדריך ההתקנה של שבוע 1, סעיף 4.
- "חסרים: js/exercises.js" — העתקת את הקבצים ולא את התיקיות. העתק את `js/` ו-`vendor/` כמו שהן.
- "תבניות הפרויקט — חסרים" — `project/templates/` לא במאגר שלך. העתק אותה מהחומרים של הפרויקט.
- "קומיטים עדיין לא נדחפו" — `git push`. אם הוא נכשל — `setup/git-panic-he.md` של שבוע 1.

## ומה עם AI

לא צריך. אם משהו כאן לא ברור, שאל את Claude מה הפקודה עושה — **ואז הרץ אותה בעצמך.** בשיעור, אחרי
ההפסקה, הוא יכתוב בשבילך קוד — מתוך מפרט שתכתוב קודם.
