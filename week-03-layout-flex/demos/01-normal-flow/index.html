Normal flow

This paragraph is a block box. It takes the whole width it is offered, and the next block box starts underneath it. Nobody asked for that: it is what the browser does when you say nothing.

Inline content flows

Inside a block box, text and inline boxes are poured into line boxes — horizontal strips as wide as the block, filled one after another until the words run out. An inline box is exactly as wide as its content, and an sits on the text baseline like a very large letter.

  • A list item is a block box too.
  • So they stack.
