# שבוע 1 — פלטפורמת הווב, HTML סמנטי ו-Git

כאן נמצאת העבודה שלך משבוע 1.

## איך עובדים כאן

1. משוך את החומרים החדשים מהמאגר הציבורי של הקורס (`git pull`), והעתק לכאן את תוכן תיקיית ה-`starter`.
2. פתח את התיקייה ב-VS Code והרץ דרך **Live Server**. לא בלחיצה כפולה על הקובץ.
3. כתוב במקומות המסומנים `<!-- CODE HERE -->` ו-`// CODE HERE`.
4. עשה קומיטים קטנים ותכופים תוך כדי העבודה, לא קומיט ענק אחד בסוף.

## הגשה

במודל, שני דברים בלבד: **כתובת ה-repo** ו-**ה-SHA של הקומיט**.

```bash
git add .
git commit -m "feat: ..."
git push
git log -1 --format=%H
```

ה-SHA הוא מה שמקפיא את ההגשה. דחיפה אחרי המועד לא משנה את מה שנבדק.
