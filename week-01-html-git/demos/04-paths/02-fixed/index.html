Relative paths travel with the folder

  1. images/logo.svg

    Start from the folder this file is in, then go down into images.

  2. ./about.html — same folder, said explicitly

    About this demo

  3. ../01-broken/index.html — up one folder, then down

    Back to the broken version

Rule of thumb: ../ means "up one folder from where this file lives", and it is counted from the file, never from the browser's address bar.
