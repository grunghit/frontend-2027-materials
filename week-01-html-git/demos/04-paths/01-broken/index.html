Three paths, three ways to fail

  1. file:///Users/maya/Desktop/site/images/logo.svg

    An absolute path into someone's Desktop. Nobody else has that folder.

  2. C:\Users\maya\Desktop\site\images\logo.svg

    Same mistake, Windows flavour. Backslashes are not path separators on the web.

  3. /images/logo.svg

    A leading slash means "from the root of the server", not "from this folder". On GitHub Pages the root is not where you think it is.
