> [!goal]
> כשהשיעור מתחיל, VS Code, Node ו-git מותקנים אצלך, יש לך חשבון GitHub עם מפתח, והסקריפט למטה
> מדפיס "3/3 — מוכן". **זמן הכיתה מתחיל בהקלדה של HTML, לא בהתקנה.**

בשבוע 1 אין עוד מאגר ואין עוד עמוד — את שניהם בונים בכיתה. מה שכן אפשר לעשות בבית הוא
ההתקנה: היא לוקחת עשרים דקות כשהכול הולך חלק, ושעה כשלא, ואת השעה הזאת עדיף להוציא בבית
עם המדריך ולא בכיתה על חשבון המחזור הראשון.

## מה עושים

1. **מדריך ההתקנה, סעיפים 1–5 ו-5א.** `setup/setup-he.pdf` (או `setup-he.md`): VS Code והתוספים,
   Live Server, Node, git, וההגדרות החד-פעמיות של git (שם, מייל, מעברי שורה); 5א הוא כרטיס אחד על כלי המפתחים של Chrome. שני מסלולים —
   macOS ו-Windows — בכל סעיף. נספח א בסוף מכסה את 14 השגיאות שבאמת קורות, עם הטקסט המדויק.
2. **חשבון GitHub ומפתח — סעיפים 6.1 ו-6.2.** חשבון, ואז דרך אחת להזדהות: מפתח SSH או טוקן.
   **את המאגר עצמו (6.3–6.5) לא צריך לפתוח בבית** — פותחים אותו ביחד בכיתה, במחזור 5. מי שכבר
   פתח — מצוין, וזה לא יזיק.
3. **הוכח שהמכונה מוכנה.** מכל תיקייה, בטרמינל המשולב של VS Code (``Ctrl+` `` או ``Cmd+` ``):

   ```bash
   node <נתיב לחומרים>/week-01-html-git/pre-class/verify.mjs
   ```

   (החומרים: `git clone` של מאגר החומרים הציבורי, הקישור בעמוד הקורס במודל — סעיף 7 במדריך.)

   שלוש בדיקות, וכולן עוברות: Node בגרסה 18 ומעלה · git מותקן ומוגדר עם שם ומייל · הפקודה
   `code` פותחת את VS Code מהטרמינל. אם בדיקה נכשלת — הסקריפט אומר מה, ומה לעשות.

4. **תיקיית תרגול.** העתק את התיקייה `week-01-html-git/live-code/01-empty-file-to-skeleton/start/`
   מהחומרים למקום נוח (שולחן העבודה, `Documents`) בשם `practice`, ופתח אותה ב-VS Code. יש בה
   `index.html` ריק (הערה אחת, שמוחקים בכיתה) וקובץ `.htmlvalidate.json` — הגדרות הוולידטור, זהות
   לאלה של הבודק, כדי ש-`npx html-validate@9 index.html` ידפיס אצלך בדיוק מה שהוא מדפיס אצלי.
   בכיתה מקלידים בה במחזורים 1–3, ובמחזור 5 היא נכנסת למאגר.

5. **פתח את כלי המפתחים (2 דקות).** פתח כל עמוד ב-Chrome, פתח DevTools — `Cmd+Opt+I` במק, `F12` בחלונות
   (מדריך ההתקנה, סעיף 5א) — ומצא את שלוש הלשוניות **Elements**, **Console** ו-**Network**. בכיתה נפתח
   אותם בדקה הראשונה של ההקלדה, ואין זמן לחפש איפה הם.

## אם משהו לא עובד

- `node: command not found` — Node לא מותקן או לא ב-PATH. מדריך ההתקנה, סעיף 4, ותקלה **א-1**.
- `git: command not found` — סעיף 5; ב-Windows ודא שסימנת "Git from the command line" בהתקנה.
- "git לא מוגדר" — שתי הפקודות בסעיף 5, "הגדרות שחייבים לעשות פעם אחת".
- `code: command not found` — ב-macOS: פתח את VS Code, `Cmd+Shift+P`, "Shell Command: Install
  'code' command in PATH". ב-Windows ההתקנה עושה את זה לבד אם סימנת "Add to PATH"; אחרת התקן שוב.

## ומה עם AI

לא צריך. אם משהו במדריך לא ברור, שאל את Claude מה הפקודה עושה — **ואז הרץ אותה בעצמך.**
אין לך מנוי? הכול עובד גם בצ'אט החינמי, ואין בכך שום חיסרון בקורס.
