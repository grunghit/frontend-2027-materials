## מה JSON לא יכול לשאת

| מה הכנסת     | מה יוצא כתכונה | מה יוצא כאיבר במערך |
| ------------ | -------------- | ------------------- |
| `undefined`  | מושמט          | `null`              |
| פונקציה      | מושמטת         | `null`              |
| `Symbol`     | מושמט          | `null`              |
| `NaN`        | `null`         | `null`              |
| `Infinity`   | `null`         | `null`              |
| `Date`       | **מחרוזת**     | **מחרוזת**          |
| `Map`, `Set` | אובייקט ריק    | אובייקט ריק         |
| `BigInt`     | **זורק**       | **זורק**            |
| מעגלי        | **זורק**       | **זורק**            |

**שתי השורות שזורקות הן המזל הטוב.** כל השאר משנה משמעות בשקט, ונכשל מאוחר יותר,
במקום אחר, בפונקציה שאין לה שום קשר לאחסון.

`JSON.stringify(undefined)` מחזירה `undefined` — **לא מחרוזת בכלל**.

### התאריך

`Date` יוצא כמחרוזת ISO ואין דרך חזרה בלי `reviver`. הכלל: **שמור את המחרוזת, והמר
במקום שבו אתה מציג.** שורה אחת ב-`render`, ואין איפה לשכוח אותה.

### ארבע התשובות של `load`

| המצב                   | מה מחזירים |
| ---------------------- | ---------- |
| `getItem` זרק          | `null`     |
| `getItem` החזיר `null` | `null`     |
| `JSON.parse` זרק       | `null`     |
| המבנה אינו שלך         | `null`     |
| **נשמר אוסף ריק**      | **`[]`**   |

**השורה האחרונה היא זו שנופלים בה.** אוסף ריק הוא **תשובה** — המשתמש מחק הכול — ולא
היעדר תשובה. מי שמדווח עליה כ`null` נותן למי שניקה את נתוני הדוגמה בחזרה ברענון הבא.

## שלושת המקומות

|                    | `localStorage` | `sessionStorage` | עוגייה            |
| ------------------ | -------------- | ---------------- | ----------------- |
| שורד רענון         | כן             | כן               | עד `max-age`      |
| שורד סגירת דפדפן   | כן             | **לא**           | עד `max-age`      |
| משותף ללשונית אחרת | כן             | **לא**           | כן                |
| נשלח לשרת בכל בקשה | לא             | לא               | **כן**            |
| מקום               | כ-5MB          | כ-5MB            | כ-4KB, ונדחה בשקט |

**המפתח משויך ל-origin** — סכימה, מארח ופורט — ולא לתיקייה. כל פרויקט שאתה מריץ עם
Live Server מוגש מאותו `http://127.0.0.1:5500`.

**`localStorage.clear()` מוחקת את כל ה-origin.** גם את הפרויקטים האחרים שלך. השתמש
ב-`removeItem` עם המפתח שלך.

## שש הטעויות של השבוע

1. **`setItem(key, object)`.** נשמר `[object Object]`, תמיד, לכל אובייקט בעולם.
2. **`JSON.parse` על `null` בביקור ראשון.** לא זורק, מחזיר `null`, והקריסה מגיעה
   ארבע שורות אחר כך ב-`map`.
3. **`try/catch` סביב ה-parse בלבד.** שלושה מארבעה מטענים שבורים עוברים אותו בשלום.
4. **מפתח בשם `items`.** משותף לכל פרויקט שלך על אותו פורט.
5. **`localStorage` בתור בסיס נתונים.** סינכרוני, כ-5MB, מחרוזות בלבד, בלי שאילתות,
   בלי הרשאות, ולא מאובטח.
6. **`Date` ב-state.** עובד מצוין עד הרענון הראשון.
