## Claude

בשמחה. אפשר לעשות את זה כולו בתוך `events.js`, בלי לגעת בשאר הקבצים. הוסף את זה בסוף
הפונקציה `wire()`, אחרי המאזינים הקיימים:

```js
const multi = document.querySelector('#multi');
if (multi) {
  multi.addEventListener('change', () => {
    const { books } = getState();
    // keep the filtered list in state, so other code can use it
    setState({ filtered: multi.checked ? books.filter((book) => book.copies > 1) : books });
    // hide the rows that don't match
    for (const row of document.querySelectorAll('#books li')) {
      const copies = Number(row.querySelector('.book-copies').textContent);
      row.hidden = multi.checked && copies <= 1;
    }
    document.querySelector('#shown').textContent = document.querySelectorAll('#books li:not([hidden])').length;
  });
}
```

מה זה עושה:

1. **שומר את הרשימה המסוננת ב-state** (`filtered`), כך שאם בעתיד תרצה להשתמש בה במקום אחר —
   למשל בעמוד סיכום — היא כבר שם.
2. **מסתיר את השורות** שיש להן עותק אחד, באמצעות המאפיין `hidden`. אין צורך לצייר מחדש את כל
   הרשימה, וזה מהיר יותר.
3. **מעדכן את המונה** "מוצגים" לפי מספר השורות הגלויות.

כשמורידים את הסימון, `hidden` חוזר ל-`false` בכל השורות והכול מוצג שוב.

> **מכשול.** זה עובד בהדגמה, ונשבר בחוק. נמדד על `artifact/claude-p1/`: סימון התיבה — **4 שורות
> גלויות, "מוצגים: 4"**, בדיוק מה שביקשו (השורות המוסתרות מקבלות `display: none` למרות
> `class="flex"`). ואז, **כשהתיבה עדיין מסומנת**: +1 על "המפה והים" — **6 שורות גלויות, "מוצגים:
> 6"**, הספרים של עותק אחד חזרו; הקלדת "ה" בחיפוש — "גשר על הירקון" (עותק אחד) מוצג; הוספת ספר
> של עותק אחד — הוא מופיע. והסרת "שעון החול" משאירה אותו ב-`state.filtered` — רשימה שמורה שכבר
> שקרית. שלושת החוקים, שלושתם שבורים: **מקור אמת** — `filtered` הוא עותק שני של מה ש-
> `selectVisible` כבר יודעת לחשב; **צייר אחד** — המטפל מסתיר שורות ומעדכן מונה, ו-`render` מוחק
> את זה בשינוי הבא; **כיוון אחד** — המטפל **קורא את המסך** (`textContent` של `.book-copies`) כדי
> להחליט מה נכון. "בלי לגעת בקבצים האחרים" הוא מה שביקשנו — וזו הסיבה שהתשובה הזאת היא מה שחזר.
