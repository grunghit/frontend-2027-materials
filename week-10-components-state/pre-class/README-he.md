> [!goal]
> כשהשיעור מתחיל, תיקיית המטלה יושבת ב-`week-10/` במאגר **כמו שהיא נשלחה** — המונוליט ב-`js/app.js`
> שלם — רצה ב-Live Server, הכול דחוף, והסקריפט למטה מדפיס "4/4 — מוכן". **חלון המטלה השבוע הוא
> רבע שעה**, כי הניתוח הקטן לוקח ארבעים דקות מהבלוק — ואין בו זמן להעתקת קבצים.

בשבוע 10 מפרקים יישום עובד לשלוש שכבות. המטלה מתחילה ב**תצפיות**: ארבעה רצפים על הקובץ **לפני**
שנוגעים בו. לכן: להעתיק, להריץ, **לא לתקן**.

## מה עושים

1. **העתק את תיקיית הפתיחה.** מהחומרים: את כל התוכן של `week-10-components-state/starter/` —
   כולל `js/` ו-`vendor/` — לתוך `week-10/` במאגר הסמסטר שלך.

2. **הרץ אותה פעם אחת** ב-Live Server (לא בלחיצה כפולה: `js/app.js` הוא מודול, ומודול לא נטען
   מ-`file://`). שש שורות, "מוצג: 6". **אל תפתח את `js/app.js` לעריכה** — בכיתה תבצע עליו ארבעה
   רצפים ותרשום מה ראית, ורק אחר כך תזיז שורה.

3. **קומיט ודחיפה.**

   ```bash
   git add week-10
   git commit -m "week-10: starter, untouched"
   git push
   ```

4. **הוכח שהכול במקום.** מהשורש של מאגר הסמסטר, בטרמינל המשולב של VS Code:

   ```bash
   node <נתיב לחומרים>/week-10-components-state/pre-class/verify.mjs
   ```

   ארבע בדיקות, וכולן עוברות: Node · `git` והמאגר · קובצי הפתיחה ב-`week-10/`, והמונוליט שלם ·
   הקומיט האחרון דחוף. אם בדיקה נכשלת — הסקריפט אומר מה, ומה לעשות.

5. **תיקיית תרגול.** העתק את `week-10-components-state/live-code/01-monolith-to-three-layers/start/`
   מהחומרים למקום נוח בשם `practice`, ופתח אותה ב-VS Code. יש בה ספריית ההשאלה של הכיתה בקובץ אחד
   — שם מתחיל מחזור 1. למחזורים 2 ו-3 מעתיקים בכיתה את ה-`start/` של כל אחד.

## אם משהו לא עובד

- `node: command not found` — Node לא מותקן או לא ב-PATH. מדריך ההתקנה של שבוע 1, סעיף 4.
- "חסרים: vendor/tailwind.js" — העתקת את הקבצים ולא את התיקיות. העתק את `js/` ו-`vendor/` כמו שהן.
- "js/app.js כבר לא המונוליט" — התחלת לפרק. העתק שוב את `js/app.js` מהחומרים: התצפיות קודמות.
- "קומיטים עדיין לא נדחפו" — `git push`. אם הוא נכשל — `setup/git-panic-he.md` של שבוע 1.

## ומה עם AI

לא צריך. אם משהו כאן לא ברור, שאל את Claude מה הפקודה עושה — **ואז הרץ אותה בעצמך.** ואל תבקש
ממנו לפרק את `js/app.js` מראש: בשעה 120 של השיעור תשב חצי שעה לבד, בלי AI, מול יישום שלא ראית,
ותצטרך לדעת לעשות את זה בידיים.

אין לך מנוי? הכול עובד גם בצ'אט החינמי, ואין בכך שום חיסרון בקורס.
