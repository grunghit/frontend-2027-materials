# חימום — חמש פונקציות קטנות, וארבע מהן שגויות

עשר דקות, **בבית, לפני הניתוח הקטן או אחריו** — בלי AI, בלי חיפוש. **אין git, אין הגשה, אין ציון.**
החימום הזה פתח פעם את שעת התרגול; בבלוק של שבוע 10 אין לו חלון (ארבעה מחזורים, הניתוח הקטן והמטלה
ממלאים את 180 הדקות), והוא נשאר כתרגול לבד על אותם חמישה רעיונות, בקטן.

## מה עושים

1. פתח את `index.html` עם Live Server והשאר אותו פתוח.
2. השופט מריץ את חמש הפונקציות שב-`warmup.js` ומדווח, לכל אחת, **מה ציפה ומה קיבל**.
3. תקן ב-`warmup.js` עד שהמונה אומר חמש מתוך חמש. **רענן אחרי כל שינוי.**

## מה כדאי לדעת לפני שמתחילים

- **ארבע מהחמש שגויות ואחת כבר תקינה.** "לשנות הכול" אינה אסטרטגיה — צריך לדעת איזו.
- אף אחת מהן אינה שגיאת תחביר. כולן רצות.
- השופט אומר מה קיבל, ולא איזו שורה אשמה. זה בכוונה: **בדיוק זה מה שהניתוח הקטן מבקש**
  (דקה 120 של הבלוק), על יישום שלם במקום על חמש פונקציות.

## מה יש כאן, מעבר לתרגיל

חמש הפונקציות אינן אקראיות. כל אחת מהן היא חתיכה של הארכיטקטורה שהקלדת במחזורים 1–3,
בזעיר אנפין:

| הפונקציה        | איזו שכבה                             |
| --------------- | ------------------------------------- |
| `selectVisible` | גזירה — `state` נכנס, מה שמוצג יוצא   |
| `itemRow`       | רכיב — פריט נכנס, אלמנט יוצא          |
| `selectCounts`  | גזירה שנייה, שחייבת להסכים עם הראשונה |
| `bumpOne`       | שינוי אוסף שמחזיר אוסף חדש            |
| `subscribe`     | החיווט שבזכותו המסך עוקב              |

**שתיים מהבדיקות אינן על הפלט אלא על החוקים** — "לא שינית את מה שקיבלת" ו"החזרת משהו
שאפשר לקרוא לו". שתי השאלות האלה הן מה שהשבוע עשוי ממנו, ואף אחת מהן לא נראית בערך
המוחזר.

## אם נתקעת

לכל פונקציה יש JSDoc שאומר במילים מה היא **אמורה** לעשות. קרא אותו לפני שאתה קורא את
הקוד. שלוש מהארבע השגויות עושות בדיוק את מה שכתוב בהן — פרט למילה אחת.

והרמז שמכסה שתיים מהארבע: **מה קיבלת, ומה החזרת — האם זה אותו אובייקט?**
