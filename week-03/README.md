# שבוע 3 — יסודות CSS וטוקנים של עיצוב

כאן נמצאת העבודה שלך משבוע 3.

## איך עובדים כאן

1. לפני השיעור: העתק לכאן את `week-02/index.html`, `about.html` ו-`images/` שלך, הוסף שורת `link` בכל עמוד, וצור `styles.css` (ראה `pre-class/README-he.md` בחומרי השבוע במודל). מי שאין לו עמוד משבוע 2 — תוכן תיקיית ה-`starter` מחומרי השבוע במודל.
2. פתח את התיקייה ב-VS Code והרץ דרך **Live Server**. לא בלחיצה כפולה על הקובץ.
3. כותבים רק ב-`styles.css`, במקומות המסומנים `/* CODE HERE */`. ה-HTML לא משתנה מלבד שורת ה-`link` והמחלקה `lede`.
4. עשה קומיטים קטנים ותכופים תוך כדי העבודה, לא קומיט ענק אחד בסוף.

## הגשה

במודל, שני דברים בלבד: **כתובת ה-repo** ו-**ה-SHA של הקומיט**.

```bash
git add .
git commit -m "feat: ..."
git push
git log -1 --format=%H
```

ה-SHA הוא מה שמקפיא את ההגשה. דחיפה אחרי המועד לא משנה את מה שנבדק.
