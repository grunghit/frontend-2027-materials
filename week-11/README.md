# שבוע 11 — שכבת הנתונים: JSON, localStorage, async, fetch

כאן נמצאת העבודה שלך משבוע 11: המזווה, עם שתי שכבות חדשות — `js/storage.js`, שבזכותו מה שנשמר נשאר מחר, ו-`js/api.js`, שמדבר עם קטלוג איטי שלפעמים לא עונה.

## איך עובדים כאן

1. לפני השיעור: הורד את חומרי השבוע מהמודל, העתק לכאן את כל התוכן של תיקיית ה-`starter` — כולל `js/`, `data/` ו-`vendor/` — ודחוף (ראה `pre-class/README-he.md` בחומרי השבוע במודל).
2. פתח את התיקייה ב-VS Code והרץ דרך **Live Server** — לא בלחיצה כפולה על הקובץ: `js/app.js` הוא מודול, ומ-`file://` שום דבר לא נטען.
3. **בכיתה, חלק א:** `js/storage.js` בחוזה של הפרויקט — המפתח `pantry:v1`, הערך הוא המערך עצמו, ומפתח שאינו קיים הוא מזווה ריק. כותבים במקומות המסומנים `// CODE HERE`.
4. בבית: העריכה, `js/api.js`, חמשת המצבים, והקטלוג אל האוסף. `js/app.js` **לא משתנה**.
5. עשה קומיט לכל חלק, עם הודעה שאומרת מה השתנה. אחרי ההגשה — העתק את `js/storage.js` ואת `js/api.js` ל-`project/`.

## הגשה

במודל, שני דברים בלבד: **כתובת ה-repo** ו-**ה-SHA של הקומיט**.

```bash
git add .
git commit -m "feat: ..."
git push
git log -1 --format=%H
```

ה-SHA הוא מה שמקפיא את ההגשה. דחיפה אחרי המועד לא משנה את מה שנבדק.
