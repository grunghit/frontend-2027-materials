# שבוע 12 — TypeScript, והניתוח המלא

כאן נמצאת העבודה שלך משבוע 12: מטלת כיתה 12 — העברת שכבת הרשת של המזווה (`js/api.js`) ל-TypeScript,
בלי לשנות שום דבר שהיישום עושה.

## איך עובדים כאן

1. **פעם אחת, לפני השיעור:** `npm install --global typescript@5.9.3`, ואז `npx tsc --version` מדפיס
   `Version 5.9.3`. במאגר הזה אין `package.json`, ו-`npx` מוצא את ההתקנה הגלובלית בלי רשת.
2. הורד את חומרי השבוע מהמודל, והעתק לכאן את תוכן תיקיית ה-`starter`.
3. פתח את התיקייה ב-VS Code והרץ דרך **Live Server**. לא בלחיצה כפולה על הקובץ.
4. **המפרט ראשון:** מלא את `specs/ts-migration.md` ועשה לו קומיט **לפני** שאתה נוגע ב-`ts/`. ההיסטוריה היא
   הראיה שהוא נכתב ראשון.
5. כתוב במקומות המסומנים `// CODE HERE`, והרץ `npx tsc -p tsconfig.json` מתוך התיקייה הזאת. הפלט נכתב
   ל-`js/` — **והוא מה שהדפדפן טוען, ולכן הוא נכנס לקומיט.**
6. עשה קומיטים קטנים ותכופים תוך כדי העבודה, לא קומיט ענק אחד בסוף.

## הגשה

במודל, שני דברים בלבד: **כתובת ה-repo** ו-**ה-SHA של הקומיט**.

```bash
git add .
git commit -m "feat: ..."
git push
git log -1 --format=%H
```

ה-SHA הוא מה שמקפיא את ההגשה. דחיפה אחרי המועד לא משנה את מה שנבדק.

**והפרויקט מוגש בסוף שיעור 12** — העתק את `ts/` ואת `tsconfig.json` גם ל-`project/`, ואל תשכח את
`AI_USAGE.md`.
