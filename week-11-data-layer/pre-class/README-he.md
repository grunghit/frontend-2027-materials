> [!goal]
> כשהשיעור מתחיל, תיקיית המטלה יושבת ב-`week-11/` במאגר **כמו שהיא נשלחה** — שני השלדים,
> `js/storage.js` ו-`js/api.js`, עוד ריקים — רצה ב-Live Server, הכול דחוף, והסקריפט למטה מדפיס
> "5/5 — מוכן". **חלון המטלה השבוע הוא חצי שעה** (145–175), ואין בו זמן להעתקת קבצים.

בשבוע 11 מוסיפים למזווה שתי שכבות: אחסון שבזכותו מה שנשמר נשאר מחר, ורשת שמדברת עם קטלוג. את
שתיהן כותבים קודם על יישום אחר בכיתה, ורק אחר כך על המזווה. לכן: להעתיק, להריץ, **לא לכתוב**.

## מה עושים

1. **העתק את תיקיית הפתיחה.** מהחומרים: את כל התוכן של `week-11-data-layer/starter/` — כולל
   `js/`, `data/` ו-`vendor/` — לתוך `week-11/` במאגר הסמסטר שלך.

2. **הרץ אותה פעם אחת** ב-Live Server (לא בלחיצה כפולה: `js/app.js` הוא מודול, ומודול לא נטען
   מ-`file://`). **מזווה ריק**, עם הכפתור "טען פריטים לדוגמה". לחץ עליו, ואז רענן — **הכול נעלם.**
   זה בדיוק מה שהשבוע מתקן. **אל תפתח את `js/storage.js` לכתיבה** — בכיתה תכתוב את אותה שכבה
   קודם על ספריית ההשאלה.

3. **קומיט ודחיפה.**

   ```bash
   git add week-11
   git commit -m "week-11: starter, untouched"
   git push
   ```

4. **הוכח שהכול במקום.** מהשורש של מאגר הסמסטר, בטרמינל המשולב של VS Code:

   ```bash
   node <נתיב לחומרים>/week-11-data-layer/pre-class/verify.mjs
   ```

   חמש בדיקות, וכולן עוברות: Node · `git` והמאגר · קובצי הפתיחה ב-`week-11/`, והשלד של
   `js/storage.js` במקום · `data/catalogue.json` תקין · הקומיט האחרון דחוף. אם בדיקה נכשלת —
   הסקריפט אומר מה, ומה לעשות.

5. **תיקיית תרגול.** העתק את `week-11-data-layer/live-code/01-build-the-layer/start/` מהחומרים
   למקום נוח בשם `practice`, ופתח אותה ב-VS Code. זו ספריית ההשאלה של שבוע 10 — שם מתחיל מחזור 1.
   למחזורים הבאים מעתיקים בכיתה את ה-`start/` של כל אחד.

## אם משהו לא עובד

- `node: command not found` — Node לא מותקן או לא ב-PATH. מדריך ההתקנה של שבוע 1, סעיף 4.
- "חסרים: vendor/tailwind.js" או "data/catalogue.json" — העתקת קבצים ולא תיקיות. העתק את `js/`,
  `data/` ו-`vendor/` כמו שהן.
- "js/storage.js אינו השלד שנשלח" — התחלת לכתוב. העתק אותו שוב מהחומרים: כותבים אחרי המחזורים.
- "קומיטים עדיין לא נדחפו" — `git push`. אם הוא נכשל — `setup/git-panic-he.md` של שבוע 1.

## ומה עם AI

לא צריך. אם משהו כאן לא ברור, שאל את Claude מה הפקודה עושה — **ואז הרץ אותה בעצמך.** ואל תבקש
ממנו לכתוב את `js/storage.js` מראש: במחזור 5 תראה בדיוק מה הוא כותב כשלא אומרים לו את הכללים.
