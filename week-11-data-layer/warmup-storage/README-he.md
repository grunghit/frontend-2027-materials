# חימום — חמש פונקציות קטנות, וארבע מהן שגויות

עשר דקות, לבד ובלי AI — תרגול לפני המטלה או אחריה; הוא לא חלק מהבלוק של שבוע 11. **אין git, אין הגשה, אין ציון.**

## מה עושים

1. פתח את `index.html` עם Live Server והשאר אותו פתוח.
2. השופט מריץ את חמש הפונקציות שב-`warmup.js` ומדווח, לכל אחת, **מה ציפה ומה קיבל**.
3. תקן ב-`warmup.js` עד שהמונה אומר חמש מתוך חמש. **רענן אחרי כל שינוי.**

## מה כדאי לדעת לפני שמתחילים

- **ארבע מהחמש שגויות ואחת כבר תקינה.** "לשנות הכול" אינה אסטרטגיה.
- אף אחת מהן אינה שגיאת תחביר. כולן רצות, וכולן מחזירות משהו.
- **אף אחת מהן לא נוגעת ב-`localStorage`.** כולן טהורות: ערך נכנס, ערך יוצא. זו לא
  הקלה לצורך התרגיל — זו בדיוק הסיבה ששכבת אחסון אפשר בכלל לבדוק.

## מה יש כאן, מעבר לתרגיל

חמש הפונקציות הן חמשת החלקים של `js/storage.js` — השכבה של מחזורים 1–2 ושל חלק א במטלה:

| הפונקציה         | איזה חלק בשכבה                                |
| ---------------- | --------------------------------------------- |
| `parseSafely`    | הפירוק שלא זורק                               |
| `readCollection` | תמיד מערך: מפתח שאינו קיים הוא אוסף ריק, ושורה פגומה עולה שורה אחת |
| `toPayload`      | מה שנכנס בפועל ל-`setItem` — המערך עצמו, בלי מעטפה |
| `isItem`         | בדיקת המבנה — כי JSON תקין אינו נתונים תקינים |
| `stampCreated`   | שדה שחייב לשרוד את המסע הלוך ושוב             |

**שלוש מהבדיקות אינן על הערך המוחזר.** "לא זרקת על זבל", "לא שינית את מה שקיבלת" ו"מה
שייצרת שורד מסע הלוך ושוב" — שלוש השאלות שהשבוע עשוי מהן, ואף אחת מהן לא נראית בערך
שהפונקציה מחזירה.

## אם נתקעת

לכל פונקציה יש JSDoc שאומר במילים מה היא **אמורה** לעשות. קרא אותו לפני שאתה קורא את
הקוד. שלוש מהארבע השגויות עושות בדיוק את מה שכתוב בהן, פרט למילה אחת.

והרמז שמכסה שתיים מהארבע: **מה בדיוק מקבל `localStorage.setItem`, ומה בדיוק חוזר
מ-`JSON.parse`?** בשני המקרים התשובה היא מחרוזת, ובשני המקרים היא לא מה שכתוב בקוד.
