# API מקומי — כשהרשת של המעבדה לא משתפת פעולה

שרת קטן שרץ אצלך במחשב. **אין מה להתקין** — Node לבדו, בלי חבילות, כי הוא צריך לעבוד גם
על מחשב במעבדה בלי אינטרנט.

```bash
node mock-api/server.mjs
# http://127.0.0.1:5510
```

## מתי משתמשים בו

**שתי סיבות, והשנייה חשובה יותר.**

1. **ה-API שבחרת לא נגיש מהחדר.** קורה. מכוונים את `ENDPOINT` שב-`js/api.js` אל
   `http://127.0.0.1:5510/search?q=...` וממשיכים. מבנה התשובה זהה לזה שב-`data/catalogue.json`,
   ולכן שום דבר אחר בקוד שלך לא משתנה.

2. **תקלות שאי אפשר לקבל משרת אמיתי מתי שרוצים.** אף API לא יחזיר לך 500 כי ביקשת, ואף
   אחד לא ייתקע לשמונה שניות בפקודה. **זה כן** — וזו כל הסיבה שאפשר בכלל לבדוק את נתיב
   השגיאה.

| הכתובת                         | מה חוזר                                       |
| ------------------------------ | --------------------------------------------- |
| `/search?q=קמח`                | תשובה רגילה                                   |
| `/search?q=קמח&fail=404`       | 404, עם מסמך שגיאה שהוא **JSON תקין לחלוטין** |
| `/search?q=קמח&fail=500`       | 500                                           |
| `/search?q=קמח&fail=html`      | **200** שהגוף שלו HTML — עמוד התחברות         |
| `/search?q=קמח&fail=truncated` | 200 שהגוף שלו אינו JSON תקין                  |
| `/search?q=קמח&delay=8000`     | תשובה רגילה, שמונה שניות באיחור               |
| `/search?q=קמח&hang=1`         | **לא עונה לעולם**                             |
| `/search?q=זזזז`               | תוצאה ריקה אמיתית                             |

> [!note] שים לב לשתי השורות שנראות הכי דומות
> `fail=404` מחזיר גוף JSON תקין, ו-`fail=html` מחזיר **200**. אלה שתי התקלות שקוד בלי
> בדיקת `res.ok` נופל בהן, ושתיהן נראות בקונסולה כמו באג בנתונים ולא כמו באג ברשת.

## שורה אחת ששווה להסתכל עליה

בקובץ `server.mjs` יש שורה אחת:

```js
res.setHeader('access-control-allow-origin', '*');
```

**זה כל ההבדל** בין API שהדפדפן ייתן לך לקרוא לבין אחד שלא. הפוך אותה להערה, רענן את
העמוד שלך, ותקבל בדיוק את מה שה-API של ויקיפדיה בלי `origin=*` נותן לך: הבקשה יוצאת, השרת עונה, וה-JavaScript
שלך מקבל `TypeError: Failed to fetch` בלי שום פרט.

**השרת לא יודע ולא מעניין אותו מי שואל.** הדפדפן הוא זה שמסרב.

## למה זה לא חלק מהמטלה

כי mock שתמיד עובד לא מלמד כלום על רשת שלא. **את המטלה עושים מול API אמיתי.** את זה
מריצים כשהאמיתי לא זמין, וכשרוצים לראות 500 בלי לחכות לתקלה של מישהו אחר.
