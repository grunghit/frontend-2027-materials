כאן נמצאת העבודה שלך משבוע 9: אתגר הניפוי (`debug/` ו-`debug-he.md`), ושלושת העמודים של הפרויקט שלך — רשימה שנבנית ממערך, הוספה והסרה, וטופס שנכשל יפה.

## איך עובדים כאן

1. לפני השיעור: הורד את חומרי השבוע מהמודל, העתק לכאן את כל התוכן של תיקיית ה-`starter` — כולל `js/`, `vendor/` ו-`debug/` — ודחוף (ראה `pre-class/README-he.md` בחומרי השבוע במודל).
2. **את `debug/` לא פותחים עד האתגר.** הוא שבור בכוונה. באתגר: 35 דקות, לבד, בלי AI, בלי חיפוש ובלי חבר — ומתקנים רק ב-`debug/js/app.js`, וממלאים את `debug-he.md`.
3. את העמודים פותחים ב-VS Code ומריצים דרך **Live Server** — לא בלחיצה כפולה על הקובץ: הקוד כאן מודולים. כותבים במקומות המסומנים `CODE HERE`.
4. עשה קומיטים קטנים ותכופים תוך כדי העבודה, לא קומיט ענק אחד בסוף: קומיט לאתגר בסוף השיעור, ואחר כך קומיט לכל חלק.

## הגשה

במודל, שני דברים בלבד: **כתובת ה-repo** ו-**ה-SHA של הקומיט**.

```bash
git add .
git commit -m "feat: ..."
git push
git log -1 --format=%H
```

ה-SHA הוא מה שמקפיא את ההגשה. דחיפה אחרי המועד לא משנה את מה שנבדק.
